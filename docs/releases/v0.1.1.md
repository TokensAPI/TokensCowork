# TokensHarness v0.1.1

本版本修正 TokensHarness 的桌面更新边界，避免应用接收上游 DSH Desktop 的错误更新，同时完善产品下载入口和候选插件源码固定。

## 本次更新

### 新增

- 新增中英文桌面端下载页面，为 Windows 与两种 macOS 架构提供统一下载入口。
- 固定 Skills UI、飞书连接和 TokensHarness 版本更新插件的候选源码提交，供后续通过产品与许可证门禁后接入。

### 修复

- 停用上游 `desktop-updates` 插件，防止 TokensHarness 被 DSH Desktop 的官方更新源错误覆盖。
- 修复下载页面的 GitHub Pages 部署认证配置。

### 优化

- 集中版本更新插件的产品名、发布仓库和下载行为配置，减少后续产品化调整的分散改动。
- 完善下载页面的双语文案和发布渠道说明。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.1-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.1-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.1-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 若构建使用 ad-hoc 签名且首次启动被 Gatekeeper 阻止，请右键应用并选择“打开”。

## 验证结果

- Windows amd64：由 GitHub Actions 构建 NSIS 安装器，验证 PE 文件并校验 SHA-256。
- macOS arm64：由 Apple Silicon Runner 构建，检查二进制架构、代码签名与 DMG 完整性。
- macOS amd64：由 Intel Runner 构建，检查二进制架构、代码签名与 DMG 完整性。
- macOS 在完整发布凭据存在时执行 Developer ID 签名、公证和 staple，否则生成经严格校验的 ad-hoc 签名版本。
- 三个平台产物必须来自同一 `0.1.1` 版本和同一 Git commit；任一平台失败时不创建 Release。
- 构建执行 Desktop 测试、类型检查、运行时闭包与生产依赖许可证门禁。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 候选产品插件尚未登记为默认分发插件，本版本不会将它们打入安装包。
- `dsh-vision-router` 因其 `potrace` 依赖采用 GPL-2.0，仍不分发进 MIT 安装包。

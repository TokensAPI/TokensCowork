# TokensHarness v0.1.5

本版本更新内置插件并修复旧 desktop profile 与产品内置插件重复加载导致的 Windows 启动失败，同时改进版本更新状态和下载进度的展示。

## 本次更新

### 新增

- 版本更新插件在侧栏展示安装包下载进度，更新过程更加直观。

### 修复

- 启动时自动移除旧 profile 中由产品托管的插件 bundle，避免 `tokens-version-updates` 或 `tokens-model-manager` 重复注册。
- Windows GUI 启动缺少有效 stderr 管道时不再由 `EPIPE` 掩盖原始启动错误。

### 优化

- 更新状态移至设置入口附近，并缩小更新按钮尺寸，减少侧栏占用。
- 将 `@tokens/dsh-version-updates` 更新至提交 `7d112a198858e140a9bd6f88b56e550059fba605`；`@tokens/dsh-model-manager` 保持在最新提交 `c4a39e7a2199678ca4bc1854c17e7b1f2e4adc61`。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.5-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.5-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.5-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- Windows amd64：桌面构建、类型检查、运行时闭包、许可证门禁与产品品牌验证通过。
- macOS arm64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- macOS amd64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- 三平台产物必须使用同一 `0.1.5` 版本、Git commit 和已公布的 SHA-256。
- staging 装配注入 2 个默认插件（版本更新、模型管理），布局校验核对全部子模块钉定。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 模型路由请求 TokensAPI 需要有效的 `TOKENSAPI_API_KEY` 凭据。

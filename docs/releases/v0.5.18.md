- 插件市场默认打开“发现”卡片页，隐藏“可安装”页签；仍可进入“已安装”统一管理可选插件。

### Windows

1. 下载 Windows amd64 安装器，完全退出正在运行的 TokensCowork。

1. 在“关于本机”中确认处理器类型，选择 Apple Silicon 或 Intel 安装包。

Apple Silicon 和 Intel 安装包使用 Developer ID 签名与 Apple 公证流程；本版本结果需在构建完成后核对。

## What's New

The plugin market opens on Discover, marks installed plugins directly, and checks for updates automatically in plugin details.

### 🎨 Improvements

- The plugin market opens on the Discover card view and hides the Installable tab. Installed remains available for managing optional plugins.
- Installed plugins in Discover show gray cards and an Installed badge. Cards stay gray on hover and remain clickable for details and management; installation and removal refresh the local inventory.
- Opening an installed optional plugin's details automatically checks for updates and offers update and uninstall actions. Retry appears only after a failed check; updates and removal retain the confirmation and restart flow.
- Failed local inventory reads offer Retry. Installed retains a shared update-check action and offline management; built-in components are excluded from the removable optional-plugin list.

|---|---|---|

| TokensCowork Updates | 0.1.1 | Application update checks and downloads |

| TokensAPI Account | 0.1.7 | Browser sign-in and account API key configuration |

| Web Search | 0.2.0 | Multi-engine web search with automatic fallback |

## Installation

### Windows Installation

1. Download the Windows amd64 installer and fully quit TokensCowork.
2. Run the installer and follow its instructions.
3. Signing status and system prompts: The Windows installer is not Authenticode-signed and may trigger SmartScreen. Verify that it came from this repository’s release.

### macOS Installation

1. Check your processor in About This Mac and select the Apple Silicon or Intel installer.
2. Fully quit TokensCowork, open the DMG, and drag the application into Applications.
3. Open TokensCowork from Applications. If the first-launch confirmation appears, click Open.

Apple Silicon and Intel installers use Developer ID signing and Apple notarization; this version’s results will be verified after the build.

## Known Limitations

- The text guard uses repeated-line thresholds and a character cap and cannot guarantee detection of every semantic loop. IM icon overlap, glass-panel font clarity and the residual Settings outline remain unresolved.
- Plugin cards on the English download page retain some Chinese names and descriptions; this update does not change that copy. Gray market cards have not been visually accepted under real-host themes.
- Automated checks do not replace real-model and cross-platform manual installation acceptance. Windows has no signing configuration; this version’s macOS signing and notarization results require post-build verification.

# TokensHarness v0.3.13

本预发布版本修复 Windows 受限命令执行时控制台窗口闪现的问题，并首次默认启用 Tokens Cowork UI 界面插件。

## 本次更新

### 新增

- Tokens Cowork UI 0.2.9 随安装包默认启用：提供品牌视觉、主题皮肤、技能入口和侧栏界面扩展。

### 修复

- 修复 Windows 每次执行受限 PowerShell 命令时屏幕闪现黑色控制台窗口的问题：上一版的 ACL 宿主控制台采用"创建后立即隐藏"，创建与隐藏之间的一帧窗口对用户可见。现改为将 ACL runner 连接到以 CREATE_NO_WINDOW 启动的无窗口辅助宿主——控制台从创建起就没有窗口，闪现在结构上不再可能。辅助宿主等待 runner 进程结束后自行退出，runner 崩溃或被强杀也不会残留进程；辅助宿主启动被安全软件拦截时降级为原有的创建即隐藏路径。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 正常升级会自动卸载旧版本并保留 `%APPDATA%\TokensHarness` 用户数据。
3. 如果旧文件仍被占用，先完全退出 TokensHarness 和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入"应用程序"。
3. 未正式公证的构建首次启动时，需要右键应用并选择"打开"。

## 验证重点

1. 桌面快捷方式启动后连续执行多条受限 PowerShell 命令，全程无控制台窗口闪现，输出正常。
2. 命令执行后无残留 powershell 辅助进程；工作区内可写、工作区外写入仍被拒绝。
3. Tokens Cowork UI 品牌视觉、主题与侧栏正常加载。
4. 从 v0.3.12 覆盖升级正常，用户数据保留。

## 验证结果

- 无窗口辅助宿主经真机验证：连接成功（38ms）、控制台无窗口、模拟 runner 崩溃后辅助进程自行退出无残留。
- 连续 10 条受限命令端到端通过，写边界（工作区内成功/区外拒绝）不变，执行前后无进程残留。
- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- 受限沙箱基础设施熔断为会话级：触发后需重启会话恢复对应受限模式。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

## 本次更新

### ✨ 新功能与优化

- 插件详情里新增「更新了什么」：有新版本时列出从已装版本到新版本之间每一版的更新说明，没有新版本时显示当前版本的说明；内容较长时可以展开。点「更新」时，确认框里也会列出这些说明。说明按界面语言显示中文或英文，只有一种语言时注明。说明读不到时不影响安装和更新。
- 左下角点下载新版本时，先弹出这一版的更新内容（摘要、要点和「查看完整说明」），点「下载」才开始；点「稍后」不下载，左下角仍显示可更新（TokensCowork 更新插件 0.2.1）。

### ⚠️ 其他变更

- 插件的更新说明由插件市场提供：取自插件安装包里的更新记录，也可以由管理员在市场后台填写；还没有填写的版本显示「这一版没有填写更新说明」。
- 产品版本使用 v0.7.22，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### ✨ Features and Improvements

- Plugin details now show what changed: when an update is available, the notes of every version from the installed one to the new one are listed; otherwise the notes of the current version are shown, and long notes can be expanded. The same notes appear in the confirmation when you click "Update". Notes follow the interface language and say so when only the other language exists. If notes cannot be read, installing and updating still work.
- Clicking the download button at the bottom left first shows what the new version contains (summary, highlights and "View Full Notes"); the download starts only after "Download". "Later" downloads nothing and the update stays available (TokensCowork Updates plugin 0.2.1).

### ⚠️ Other Changes

- Plugin release notes come from the plugin market: taken from the changelog in the plugin package, or written by an administrator in the market console; a version without notes shows that none were written.
- The product version is v0.7.22 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

TokensCowork Updates plugin 0.2.1: plugin CI passed on Node 22, 24 and 26; 24 real-host contract tests passed and all 25 mutation checks hit; the new cases fail on the old code. Plugin release notes: the market read endpoint is live, returning 404 without a Key and 200 with one for a restricted plugin; the in-app display is covered by market component tests (update available, not installed, language fallback, folding, no HTML executed, unreadable notes never block an update). The overlay registry check found no drift and build-code regression passed. Installation and interface acceptance of the v0.7.22 installers on real devices have not been performed yet; this version is first offered only to internal accounts through the market's staged-delivery page.

## Known Limitations

Same as v0.7.21: downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request; GPT and Codex models are not usable through TokensAPI for now and are hidden from the model list by default.

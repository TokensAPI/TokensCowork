# TokensHarness v0.2.1

本版本在 v0.2.0 纯净稳定版基础上，仅内置最新版 TokensHarness 版本更新插件，其他产品插件继续由用户按需安装。

## 本次更新

### 产品调整

- 内置 `@tokens/dsh-version-updates` 0.1.0，固定到远程 `main` 最新提交 `7d112a198858e140a9bd6f88b56e550059fba605`。
- 继续关闭官方 DSH Desktop 更新服务，改由 TokensHarness 更新插件检查本仓库的 latest 稳定 Release。
- 不内置模型管理、飞书连接、TokensAPI UI 或其他额外插件。
- 保留 v0.2.0 的桌面基础能力、品牌配置、卸载行为和固定上游源码版本。

### 更新能力

- 支持从侧栏或托盘手动检查 TokensHarness 新版本，并在已打包的 Windows 与 macOS 应用中下载匹配架构的安装包。
- 下载完成前校验 Release 声明的文件大小与 SHA-256；本地已有安装包只有通过完整校验才会复用。
- 后台轮询只在已打包应用中启用，开发态不会自动联网检查更新。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.2.1-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.2.1-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.2.1-macos-amd64-installer.dmg` |

正式安装包仅从本仓库的 `v0.2.1` GitHub Release 下载，并使用同一 Release 中的 `TokensHarness-0.2.1-SHA256SUMS.txt` 校验。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库正式 Release。
3. 启动后由内置版本更新插件检查后续 TokensHarness 稳定版本。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 版本更新插件独立测试共 175 条，全部通过。
- 产品布局必须只包含 `tokens-version-updates` 一个默认插件，并固定插件仓库、提交、包名和版本。
- 云端构建继续执行完整 profile 启动、运行时闭包、生产依赖许可、产品品牌和安装包校验。
- Windows amd64、macOS arm64 与 macOS amd64 全部成功后才创建稳定 Release。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 更新检查依赖 GitHub latest Release 接口及安装包下载地址可访问。

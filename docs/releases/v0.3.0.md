# TokensHarness v0.3.0

本版本是跟随最新 DSH Desktop 上游的纯净正式版，不内置 TokensHarness 产品插件，适合希望使用基础桌面能力并自行选择插件的用户。

## 本次更新

### Windows 安装器

- 保留 NSIS 3.12 的长路径支持，同时固定经过验证的 Unicode NSIS 插件资源，修复安装阶段 `Error opening ZIP file` 和错误信息乱码。
- Windows 发布任务会真实执行一次静默安装，不再只检查安装器文件和压缩包结构。

### 上游桌面

- DSH Desktop 固定到提交 `d457d790295e727bbb1fc20e398da602f521fd64`，包含 macOS 原生应用菜单本地化和 Market 操作失败详情改进。
- DeepSeek Harness 保持 Desktop 官方固定的提交 `141eb6fef83422698aef7a981029e843e8161534`，不混用尚未由 Desktop 验证的新版本。
- 桌面工作区使用上游 `2.0.2` 构建布局及 DSH `0.1.0-rc.8` 依赖图。

### 纯净产品

- 版本更新、飞书连接和 TokensAPI 模型管理插件均设为不随安装包启用。
- 构建阶段不复制、编译或注入任何 TokensHarness 产品插件，也不增加其运行时依赖。
- 保留 DSH Desktop 自带的基础桌面、社区市场和插件安装能力，额外插件由用户按需安装。
- 下载页将 `v0.3.0` 标记为“纯净版”，但不会将纯净版设为默认推荐下载。

| Windows | amd64 | `TokensHarness-0.3.0-windows-amd64-installer.exe` |

安装包及对应 SHA-256 校验文件仅从本仓库 `v0.3.0` GitHub Release 下载。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Release。
3. 需要额外能力时，通过 DSH Terminal 或社区市场按需安装插件。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 产品布局检查通过，版本、Desktop gitlink、嵌套 DSH 提交及全部插件来源保持固定。
- 产品装配摘要为 `0 default plugin(s)`，staging 工作区未装配 TokensHarness 产品插件。
- Fabric 双语文档与 Market 文档、Schema 检查通过；Market 19 个测试文件、274 条测试全部通过。
- 许可证门禁检查 539 个生产依赖，Desktop 编译、类型、CLI、Loader、Profile 与 200 节点运行时闭包验证通过。
- TokensHarness 产品名称、应用 ID、运行时和安装器品牌验证通过；三个平台安装包由发布工作流继续执行原生构建与 SHA-256 校验。
- Windows 安装器必须在全新临时目录完成真实安装，解压器或安装脚本运行失败会直接阻止发布。

## 已知限制

- 本纯净版不提供 TokensHarness 应用内自动更新、TokensAPI 模型管理或飞书连接能力。
- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

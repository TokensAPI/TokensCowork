# TokensCowork v0.5.2

补齐桌面及插件市场品牌文案，并同步内置 UI 插件 0.2.22。本版本先作为预发布供验证。

## 本次更新

- 修复 Windows 快捷方式悬停说明仍显示上游名称的问题。
- 统一插件市场安装、卸载、更新、重启提示的中英文品牌。
- 补齐原生终端、加载失败、启动恢复与目录选择报错中的产品名称；保留技术标识及旧安装识别逻辑。
- 内置 dsh-tokensapi-ui 从 0.2.20 升至 0.2.22，包含隔离运行时适配、长问题展示及回合状态文案调整。
- Desktop、DSH 与其他三个内置插件固定版本不变。

## 下载说明

附件由 GitHub Build Desktop 构建，以上传结果为准。

- Windows amd64：`TokensCowork-0.5.2-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.2-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.2-macos-amd64-installer.dmg`

## 安装说明

完全退出应用后覆盖安装，升级前建议备份用户数据。不需要删除配置。旧快捷方式的悬停说明需新安装包重新创建快捷方式后验证。

## 验证结果

- UI 0.2.22 发布产物 SHA-256 校验通过，固定清单与子模块一致；59 项外层回归通过，包含新版产物的市场弹窗定位覆盖。
- 品牌修复阶段 Desktop/Market 编译、类型检查和编译产物品牌校验通过；市场 276 项通过、9 项原有跳过。这组运行验证使用 UI 0.2.20，不代表 0.2.22 已完成界面验收。
- 新版本完整装配、安装包及跨平台检查以本次 CI 结果为准。
- UI 0.2.22 已在独立 staging 完成产品源码装配，未修改正在运行的本地开发目录；依赖安装及完整运行验证由 CI 继续执行。

## 已知限制

本地 Electron 正在使用的装配目录未被覆盖。UI 0.2.22 的实际界面、Windows 快捷方式及 macOS 安装升级仍需新包真机验证；预发布不替代稳定版。

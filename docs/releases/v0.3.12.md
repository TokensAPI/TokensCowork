# TokensHarness v0.3.12

本预发布版本升级 TokensAPI 模型插件到 0.2.11，修复线路切换与模型选择的一致性问题，并更新应用图标。

## 本次更新

### 修复

- TokensAPI 模型插件升级到 0.2.11：持久化 TokensAPI 与备用线路的当前选择，重启后恢复正确模型；配置页导航与线路切换拆分，提供明确的当前线路展示与切换按钮；外层模型选择器只保留当前模型名称，不再暴露内部 provider 与实现后缀。

### 优化

- 更新应用图标。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.3.12-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.3.12-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.3.12-macos-amd64-installer.dmg` |

本版本默认作为 GitHub Pre-release 发布；验证完成后再单独确认是否进入稳定更新通道。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 正常升级会自动卸载旧版本并保留 `%APPDATA%\TokensHarness` 用户数据。
3. 如果旧文件仍被占用，先完全退出 TokensHarness 和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入"应用程序"。
3. 未正式公证的构建首次启动时，需要右键应用并选择"打开"。

## 验证重点

1. 切换 TokensAPI 与备用线路后重启应用，当前模型与线路选择保持一致。
2. 外层模型选择器只显示模型名称，无内部 provider 后缀。
3. 应用图标在任务栏、桌面快捷方式与关于页均为新版。
4. 从 v0.3.11 覆盖升级正常，用户数据保留。

## 验证结果

- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- 受限沙箱基础设施熔断为会话级：触发后需重启会话恢复对应受限模式。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

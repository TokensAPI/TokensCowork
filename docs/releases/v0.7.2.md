# TokensCowork v0.7.2

在 v0.7.1 基础上的修正版：输入框切换模型后菜单立即收起（与上游一致）；侧栏"插件"页的"发现"标签改由 TokensCowork 插件市场提供，并在启动时关闭上游的"自定义插件市场"；macOS 安装包改用更快的压缩方式缩短发布时间。内核版本与 v0.7.1 相同。

## 本次更新

### 🐛 问题修复

- 输入框的模型菜单：选中 TokensAPI 模型后菜单要等插件把选择写回路由（含一次在线模型列表刷新）才会收起，慢网络下看起来像"已切换但不关闭"，要点击空白处。"TokensAPI 模型"插件升到 0.2.25：改为先由内核确认选择（菜单随即收起，行为与上游一致），再在后台保存到路由；保存失败时按钮退回原模型并记录日志，不再弹出提示。
- 侧栏"插件"页的"发现"标签：此前是上游"自定义插件市场"的空壳（提示"添加索引源"），且 v0.7.1 把它的开关隐藏后已开启的用户无法关闭。现在启动时自动关闭该上游市场并清理其预置的索引源；"发现"标签改由 TokensCowork 插件市场提供，数据来自产品固定的私有源，安装走产品流程。

### ⚠️ 其他变更

- macOS 安装包改用 Apple 原生的 ULFO 压缩并不再生成差分更新的 blockmap（产品更新为整包下载并校验 SHA-256，从未使用它）；每个 macOS 构建任务缩短约 1.5 分钟，DMG 体积变化在百分之几以内。
- 产品版本使用 v0.7.2，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🐛 Bug Fixes

- Composer model menu: after picking a TokensAPI model the menu waited for the plugin to write the pick back to the route (including an online model-list refresh) before closing, which on slow links looked like "switched but stuck open" until you clicked elsewhere. The "TokensAPI Models" plugin 0.2.25 lets the core confirm the pick first (the menu closes right away, matching upstream) and saves it to the route in the background; a failed save reverts the button to the previous model and logs the reason instead of showing a toast.
- Sidebar Plugins page "Discover" tab: it used to be the empty shell of the upstream "custom plugin market" ("add an index source"), and after v0.7.1 hid its switch, users who had enabled it could not turn it off. The upstream market is now closed at startup (its preset index source is cleaned up) and the "Discover" tab is provided by the TokensCowork plugin market, backed by the product's fixed private source with installs going through the product flow.

### ⚠️ Other Changes

- macOS installers now use Apple's native ULFO compression and no longer emit the differential-update blockmap (the product updater downloads whole installers and verifies their SHA-256, so it was never read); each macOS build job is about 1.5 minutes shorter and DMG sizes change by a few percent at most.
- The product version is v0.7.2 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

"TokensAPI Models" 0.2.25 was checked against upstream with the core's own model-menu component on both real core lines (0.2.1-rc.2 and 0.2.0-rc.2): close on pick, no leftover rows, stay open with a toast when the core refuses, immediate close without a route write when re-picking the current model — 6/6 identical on each; plugin lint, typecheck, 937 tests and build passed. The Discover tab and market close-at-startup are two new overlays whose anchors fail the build when they drift; the overlay doctor reports every overlay effective, none broken, none obsolete; market overlay tests (43) and the build-code regression (157) passed, and on the staged tree all five Desktop tsconfig typechecks plus two suites (96 cases) and the market client's typecheck plus 338 vitest cases passed. The macOS compression change passed a three-platform rehearsal in 14.8 minutes (previously 19). The full product gate (`build.mjs check`) passed all 19 steps (assembly, immutable install, runtime patches, compaction and RPC smoke, plugin compilation and pruning, licenses, Fabric/Market checks, configuration, Desktop build, typecheck, closure/CLI/Loader/Profile verification, branding gate); the step-16 CLI smoke first aborted because of an integrity-label anomaly on the local build directory, and steps 16–19 passed on a rerun after the environment was repaired — unrelated to the product. Installation, Plugins-page and model-menu acceptance of the v0.7.2 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.0: GPT models via TokensAPI currently fail to send because the upstream channel only accepts the Codex client; the market's uninstall-then-install update has not been verified on a real device; visual acceptance of the Discover home is pending; downgrading to 0.5.x loses the display of migrated settings and sessions. If saving a model pick to the TokensAPI route fails (offline, invalid key), the button reverts to the previous model and the reason is logged; no toast is shown.

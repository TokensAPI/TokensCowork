# TokensHarness v0.3.3

本版本作为正式品牌 Logo 的桌面端预发布候选，统一 Windows、macOS、托盘和客户端界面的产品图标，并包含 v0.3.2 之后的构建目录整理与下载页信息改进。请完成跨平台真机显示和启动验证后，再决定是否提升为稳定版本。

## 本次更新

### 正式品牌 Logo

- 使用 TokensAgent 项目提供的正式 Logo 替换 Desktop 上游图标，覆盖应用图标、macOS Dock 图标、系统托盘、网页 favicon 和客户端 Logo。
- 仓库保存的正式 Logo 与来源 PNG 内容及 SHA-256 完全一致。
- Windows 应用图标只缩放到打包要求的尺寸；macOS 只增加平台安全区所需的透明边距。
- 16、20、24 和 32 像素托盘图仅按尺寸缩放，不改色、不重绘，也不增加产品文字或背景。

### 构建与下载页

- 将构建脚本按装配、插件、验证和 macOS 流程重新分层，并补充 `build/README.md` 与手动发布指南。
- 品牌资源归入 `build/assembly/assets/brand`，由 staging 装配阶段注入，不修改只读 Desktop 或插件子模块。
- 下载页增加内置插件标识符展示，便于确认安装包中实际包含的插件。
- 保持 Verified Desktop、DSH 和 4 个默认产品插件的现有固定版本不变。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.3.3-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.3.3-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.3.3-macos-amd64-installer.dmg` |

预发布安装包仅从本仓库的 `v0.3.3` GitHub Pre-release 下载，并使用同一 Release 中的 `TokensHarness-0.3.3-SHA256SUMS.txt` 校验。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Pre-release。
3. 启动后检查安装器、开始菜单、任务栏、应用窗口和系统托盘中的 Logo。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。
4. 检查 Finder、Dock、菜单栏和客户端界面中的 Logo 尺寸与透明边距。

## 建议验证

1. 在未安装 TokensHarness 的环境执行全新安装，确认安装和首次启动正常。
2. 分别检查 Windows 常用 DPI 与 macOS 浅色、深色模式下的应用和托盘图标。
3. 打开客户端页面，确认 favicon 与界面 Logo 使用同一正式图形且没有改色或背景。
4. 从 v0.3.2 升级到本版本，确认现有配置、默认插件和更新流程不受影响。

## 验证结果

- 产品 staging 装配成功，正式 Logo 来源文件、仓库文件和 staging 文件的 SHA-256 完全一致。
- Market 受控并发运行 19 个测试文件、274 项测试，全部通过。
- Desktop 构建、类型检查、CLI、Loader、Profile、品牌校验和 200 个第一方节点的运行时闭包检查通过。
- Windows amd64 与 macOS arm64、amd64 安装包将由 GitHub Actions 正式发布工作流分别构建和校验。

## 已知限制

- 本版本是 Logo 跨平台真机验证用 Pre-release，不会取代当前稳定版 `latest`。
- 小尺寸托盘图只执行等比例缩放，没有针对单个平台单独重绘，需要重点检查实际系统显示效果。
- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

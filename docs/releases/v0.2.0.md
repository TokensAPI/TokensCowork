# TokensHarness v0.2.0

本版本作为不内置任何第三方或产品插件的纯净稳定版发布，便于独立安装、升级、卸载和验证 DSH 插件。

## 本次更新

### 产品调整

- 移除安装包中的全部默认插件，包括版本更新、TokensAPI 模型管理、飞书连接和 TokensAPI UI。
- 保留 DSH Desktop 与 DeepSeek Harness 的固定上游版本，不改变基础桌面能力。
- 插件改为由用户按需通过 `dsh plugin add` 安装，并可通过 `dsh plugin remove` 独立卸载。

### 构建

- 产品版本升级至 `0.2.0`。
- 产品插件清单固定为空，构建时不复制插件源码、不注入插件 patch，也不增加插件运行时依赖。
- Windows amd64、macOS arm64 与 macOS amd64 继续使用同一固定基础依赖图构建。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.2.0-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.2.0-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.2.0-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。
3. 需要额外能力时，从 DSH Terminal 使用 `dsh plugin add <plugin>` 安装插件。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- 产品装配摘要必须显示 `0 plugin submodule(s)`。
- staging workspace、桌面宿主依赖和 Cordis 产品层不得包含任何产品插件。
- Windows 安装包必须通过版本、品牌、PE 文件和卸载数据保留校验。
- 三个平台构建成功后统一生成安装包 SHA-256 校验文件。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 本版本不提供自动更新、TokensAPI 模型管理、飞书连接或其他插件能力，需用户自行安装。

# TokensHarness v0.3.11

本预发布版本将线上 Desktop 更新为 Tokens Cowork 品牌，并内置全新的基础主题视觉，用于验证浅色与深色毛玻璃界面在正式客户端构建中的表现。

## 本次更新

### 新增

- 默认内置 `dsh-tokensapi-ui` 0.2.5，并固定到已发布、已校验的 GitHub Release 资产。
- 侧栏与新对话页应用 Tokens Cowork Logo，`Cowork` 使用蓝紫青渐变字色。
- 深色模式使用独立白色扁平 Logo，避免 3D 图标投影反白造成异物感。

### 优化

- 深度升级基础主题的浅色与深色方案，包括卡片、按钮、输入区、选择框、展开选项面板、边框与按压反馈。
- 选择组件与浮层使用半透明背景、背景模糊、内高光和多层阴影，并提供不支持模糊时的兼容性降级。
- 移除新对话页标语与 Logo 旁的“预览版”徽标，使首屏更简洁。

本版本以 GitHub Pre-release 发布，不替换当前稳定版。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 如出现 SmartScreen 提示，请确认安装包来自本仓库官方 `v0.3.11` Release。
3. 安装后分别切换浅色与深色模式，并展开 Agent 预设选择框检查毛玻璃效果。

### macOS

1. 根据设备下载 Apple Silicon 或 Intel 版本 DMG。
2. 将 TokensHarness 拖入“应用程序”；未公证构建首次启动时请右键选择“打开”。
3. 启动后执行与 Windows 相同的主题、选择组件与品牌验证。

## 验证重点

1. 浅色和深色模式下 Logo、字标与整体布局是否协调。
2. Agent 预设选择框展开后，选项面板是否呈现透明度和背景模糊。
3. 浅色按钮按压阴影是否保持圆角，不出现方形阴影边缘。
4. 现有模型、飞书、本地文件、联网搜索和插件市场功能是否保持正常。

## 验证结果

- `dsh-tokensapi-ui` 24 项测试通过，TypeScript 类型检查与生产构建通过。
- UI 插件 GitHub Release 资产下载与 SHA-256 校验通过。
- 产品布局、插件依赖许可、Desktop 完整检查和各平台安装包由本次远程 Action 执行。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 毛玻璃强度受操作系统合成器和 Electron 图形后端影响，不支持时会使用半透明实体材质降级。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

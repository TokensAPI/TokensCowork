# TokensCowork v0.3.20

修复社区市场回执与实际安装漂移时受控更新永久失效的问题。

## 本次更新

### 修复

- 市场回执与 Profile 内实际安装版本不一致时（例如历史更新升级了包但未写入回执），受控更新不再直接拒绝并把插件误判为"通过其他方式安装"。
- 漂移状态下降级到手动安装复核路径：用 npm registry 重新验证本地实际版本的仓库、integrity 与 bundle，通过后接管原地升级，并在成功后替换陈旧回执完成自愈。
- 新增对应 Host 回归测试，覆盖"陈旧回执 + 漂移安装 + 更高目录版本"的完整接管路径。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.3.20-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensCowork-0.3.20-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensCowork-0.3.20-macos-amd64-installer.dmg` |

本版本默认作为 GitHub Pre-release 发布，验证完成后可在 Release 页面转为稳定版本。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 装配后的 dsh-community-market 工作区检查通过：19 个测试文件、272 项测试全部通过（8 项为产品覆盖有意跳过的上游用例）。
- 新增回归测试 `adopts a drifted install when the market receipt no longer matches it` 通过。
- 产品装配锚点校验全部通过。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

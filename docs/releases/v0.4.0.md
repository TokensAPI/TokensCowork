# TokensCowork v0.4.0

升级到最新 Desktop、Harness 与 DSH 运行时，统一插件依赖版本，并完善插件市场、图片附件、模型同步和 Windows 桌面运行体验。

## 本次更新

### 上游升级

- Desktop 固定到 `099ef308`，DeepSeek Harness 固定到 `d347e703`，产品运行时统一为 DSH `0.1.3-alpha.1`。
- 采用最新版社区市场安装、卸载与状态刷新逻辑，修复卸载后界面仍显示“可启用”等旧状态问题。
- 图片附件支持最长边 8192 像素；超过边界时会明确拒绝，避免异常图片进入会话。

### 插件更新

- TokensAPI 模型插件升级到 0.2.15，同步当前会话模型，并优先使用受管会话默认模型。
- 连接中心升级到 2.6.0，新增钉钉个人连接能力，并更新市场展示信息。
- 保持 Tokens Cowork UI 0.2.16 与远端发布产物一致。

### 桌面与构建

- 统一全部 DSH 生产依赖为 `0.1.3-alpha.1`，不再安装旧的 `0.1.2-rc.1` 运行时。
- 适配 Windows 后台 Node 启动方式、CLI runtime smoke 和本地 CA 品牌，保留无控制台窗口的后台运行体验。
- 更新产品身份、图标生成和品牌门禁，确保运行时、安装器与本地证书均使用 TokensCowork 品牌。

本版本作为 GitHub 正式版发布。请从本仓库 Release 页面下载对应系统与架构的安装包，并使用同页校验文件核对完整性。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 社区市场完整测试通过：22 个测试文件、254 项测试通过；8 项多来源管理用例按产品固定市场源策略跳过。

- 生产运行时闭包检查通过，共覆盖 234 个一方运行时节点；许可证门禁通过，共检查 673 个生产包。
- 图片尺寸边界验证通过：8192 像素接受，8193 像素拒绝。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

# TokensCowork v0.4.6

引入原生外部 composer 输入面板与插件市场组织可见域：市场可按 TokensAPI 组织授权插件可见性并支持受控更新与后台管理完善，界面升级到 Tokens Cowork UI 0.2.19，同时优化重复构建速度与开发启动体验。

## 本次更新

### 外部 composer

- 暴露原生 DSH composer 输入面板并对齐运行时控制，外部集成方可复用产品的原生输入体验。

### 插件市场

- 组织可见域：按 TokensAPI 组织管理插件可见性（D1 组织 schema、后台组织与状态界面），公开插件不受影响；已安装插件与系统组件在市场中分组展示。
- 受控更新覆盖与市场对话框定位修正随产品装配下发。
- 市场目录改为部署时从名册现场生成，消除“改名册忘记重新生成快照”一类漂移；后台样式抽离为独立样式表。

### 界面与构建

- Tokens Cowork UI 升级到 0.2.19。
- 重复构建保留 staging 依赖，装配显著提速；品牌改写对保留的依赖幂等。
- 开发启动脚本默认真实数据模式，启动前自动关闭冲突实例。
- 构建目录按角色重组并统一命名语法（内部整理，不影响使用者）。

请从本仓库 Release 页面下载对应系统与架构的安装包，并使用同页校验文件核对完整性。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未经公证的构建首次启动时，需在系统设置的“隐私与安全性”中选择“仍要打开”。

## 验证结果

- 市场访问测试 21 项通过；四个市场覆盖自测（授权 3、更新 3、对话框定位 2、装配来源 3）通过。
- 上游 desktop-market 套件以原版 12 项通过（产品不再改写其默认值断言）。
- 产品装配在隔离 stage 完整重演通过；产品布局、版本钉定、市场名册一致性闸门全部通过。
- 完整的桌面与市场测试套件、运行时闭包、许可证门禁、预设健康检查补丁验收与品牌门禁由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- 市场授权状态以本市场为准，不自动同步 New API 的 Key 状态。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 构建未经 Apple 公证，首次打开需在系统设置中放行。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

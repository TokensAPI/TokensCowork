# TokensCowork v0.3.21

修复应用升级后社区市场把已安装插件误判为"未安装"的问题，并消除市场目录的版本漂移。

## 本次更新

### 修复

- 受控安装的匹配不再绑定升级后必然轮换的源记录号：改按稳定的 providerId、条目 id 与包名匹配，升级前安装的插件照常识别为"已安装"，不再出现点击后提示已有回执（409）与手动安装指引。
- 对齐 roster 与 product 两处插件版本号（tokens-connect、dsh-tokensapi-ui、tokens-model-manager），市场不再展示落后的版本。
- 新增市场目录一致性闸门（`yarn market:check`）：快照与名册分叉、双处版本不一致都会在部署前与发版校验时被拦下。

### 重构

- 市场目录收敛为单一来源 `market/roster.json`：线上动态目录与静态兜底快照由同一份名册生成，media-gen 不再在兜底快照中缺席。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.3.21-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensCowork-0.3.21-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensCowork-0.3.21-macos-amd64-installer.dmg` |

本版本默认作为 GitHub Pre-release 发布，验证完成后可在 Release 页面转为稳定版本。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 装配后的 dsh-community-market 工作区检查通过：19 个测试文件、273 项测试通过（8 项为产品覆盖有意跳过的上游用例）。
- 新增回归测试：源记录号轮换后旧回执仍识别为受控安装并可走更新预览。
- 市场目录一致性闸门通过：快照最新，6 个内置插件版本一致。
- 产品装配锚点校验全部通过。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

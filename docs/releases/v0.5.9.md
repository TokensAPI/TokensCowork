# TokensCowork v0.5.9

新增内置循环护栏，在工具调用重复时提供提醒和纠正反馈，缓解模型持续重复相同操作的问题。

## 本次更新

- 内置 tokens-loop-guard 0.1.0，固定提交 00b6b2444c1540d8035cac70d8ce0fd3f15d98c0，默认启用。
- 检测精确重复及命令骨架相近的调用；达到阈值时提供提醒或替换工具结果为纠正反馈。
- 启用产品护栏时停用上游 repeat-tool-reminder，避免双重提醒。
- 保留 0.5.8 的系统代理网页抓取修复及其他固定组件版本。

## 下载说明

以 pre-release 发布，安装包以 GitHub 构建成功后的附件为准。

- Windows amd64：`TokensCowork-0.5.9-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.9-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.9-macos-amd64-installer.dmg`

## 安装说明

完全退出应用后覆盖安装，无需清理会话、API Key 或插件配置。

## 验证结果

- 插件 12 项单元测试通过。
- 使用测试分支的真实 deepseek-v4-flash 模型与模拟工具结果对照：两轮关闭护栏均重复至 12 步上限；两轮开启护栏均在第 3 次提醒后于第 4 步改换行动。
- 第二轮后段及第三轮遇到 HTTP 429，未计为成功结束任务；该测试不等同完整桌面端到端验收。

## 已知限制

- 护栏属于循环缓解措施，不保证终止所有循环或自动完成任务。
- 纠正反馈发生在工具执行后，并不撤销已经执行的操作；模型忽略指引仍可能继续调用。
- 近似重复检测可能影响连续处理不同文件等正常操作，需在实际工作流中观察。
- Windows 与 macOS 安装及桌面功能仍需预发布真机验证。

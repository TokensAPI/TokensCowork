# TokensHarness v0.1.4

本版本内置模型管理插件：安装包默认提供 TokensAPI 模型路由与模型管理界面，移除上游公开 DeepSeek 路由和通用供应商编辑器，开箱即用 TokensAPI 的默认文本模型。

## 本次更新

### 新增

- 内置 `@tokens/dsh-model-manager` 插件：提供 TokensAPI 模型路由（`deepseek-v4-flash` 默认模型）与产品化的模型管理界面。
- 产品补丁层停用上游公开 DeepSeek 路由（`llm-deepseek`）与通用模型设置页（`ui-settings-models`），模型入口统一由产品插件提供。

### 修复

- 修正 `tokens-version-updates` 插件的产品钉定提交，与插件仓库最新 main 保持一致。

### 优化

- 更新插件托盘命令文案精简为 `Check Updates…`，与上游更新菜单明确区分。
- 重新生成产品依赖锁文件，纳入模型管理插件的运行时依赖（commander、undici）。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.4-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.4-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.4-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- Windows amd64：桌面构建、类型检查、运行时闭包、许可证门禁与产品品牌验证通过。
- macOS arm64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- macOS amd64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- 三平台产物必须使用同一 `0.1.4` 版本、Git commit 和已公布的 SHA-256。
- staging 装配注入 2 个默认插件（版本更新、模型管理），布局校验核对全部子模块钉定。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 模型路由请求 TokensAPI 需要有效的 `TOKENSAPI_API_KEY` 凭据。

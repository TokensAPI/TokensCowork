# TokensCowork v0.4.4

本次更新补全原生界面的产品品牌：重启确认框、系统通知、托盘菜单、恢复窗口等此前仍显示上游名称的文案全部替换为产品名。

## 本次更新

### 品牌修正

- 原生对话框（重启/更新/终端/诊断）、托盘菜单、恢复助手窗口、系统通知与原生页面标题的全部可见文案统一替换为产品品牌；此前这些界面仍显示上游名称（如“现在重启 DSH Desktop？”）。
- verify-branding 门禁同步扩展：上述 8 个文案文件在配置后不得再携带上游品牌，上游 pin 更新引入新品牌串会在装配时被拦下。
- 身份与迁移逻辑中对上游名称的引用（安装探测等）保持原样，不参与替换。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.4.4-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensCowork-0.4.4-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensCowork-0.4.4-macos-amd64-installer.dmg` |

请从本仓库 Release 页面下载对应系统与架构的安装包，并使用同页校验文件核对完整性。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 71 处上游品牌文案完成替换；重编译后的重启确认框等原生界面显示产品名。
- 产品布局、版本钉定、市场名册一致性与快照闸门全部通过。
- 完整的桌面与市场测试套件、运行时闭包、许可证门禁、预设健康检查补丁验收与品牌门禁由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

# TokensHarness v0.3.7

本稳定版本内置零配置联网搜索能力，正式为 TokensAPI 自定义模型提供原生 `web_search`、多引擎自动回退和完整桌面安装体验。

## 本次更新

### 内置联网搜索

- 新增 `tokens-dsh-web-search` 0.1.0，固定到提交 `78fd73980537221ece8bba269518f7cd1e515175`。
- 保留原生稳定工具名 `web_search`，由产品插件接管实际搜索 provider。
- 默认优先使用 Bing，并在失败或结果为空时自动回退到其他可用搜索引擎。
- 禁用需要 `DEEPSEEK_API_KEY` 的原生 DeepSeek 搜索 provider，避免重复 provider 和设置入口。
- 默认隐藏搜索设置卡；需要手动调整首选引擎时可使用 `/tokens-dsh-web-search` 命令。

### 安全与分发

- 插件移除了远程检查更新与一键升级逻辑，版本完全由 TokensHarness 产品清单固定。
- 插件源码以 Git 子模块固定到明确提交，并通过产品生产依赖许可证 gate 后进入安装包。
- `web_fetch` 继续保持关闭，不扩大现有网页抓取与 SSRF 风险边界。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。
3. 可直接覆盖安装旧版本，启动后新建会话测试 `web_search` 和 `/tokens-dsh-web-search`。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证重点

1. 新安装或覆盖安装后，无需填写额外搜索 API Key 即可调用 `web_search`。
2. 搜索结果包含来源链接，并能获取安装当日的最新公开信息。
3. 输入 `/tokens-dsh-web-search` 能打开首选引擎选择器。
4. 设置页不显示重复的原生 Web Search 卡片。
5. TokensAPI 模型、飞书连接、本地文件引用和产品更新入口保持正常。

## 验证结果

- 产品布局校验确认版本元数据、插件 Gitlink、仓库 URL 和固定提交一致。
- Web Search Host 与客户端运行时代码通过 Node.js 语法检查。
- 产品依赖锁、许可证 gate、Desktop 完整检查和 Windows 安装 smoke 由本次构建执行并记录最终结果。

## 已知限制

- 免费搜索源可能受目标站点、地区网络、共享 IP 或请求频率限制，插件会自动尝试其他引擎。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

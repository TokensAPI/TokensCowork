# TokensHarness v0.3.4

本版本是 Windows 安装性能优化的预发布候选，在保留完整应用运行能力的前提下减少安装器中的无效架构文件和调试元数据，并更新本地文件引用与模型管理插件。请重点验证全新安装、覆盖升级、首次启动和常用工具调用。

## 本次更新

### Windows 安装优化

- Windows amd64 安装包不再携带 ARM64、IA32 以及 macOS、Linux 的原生二进制文件。
- 移除 `node_modules` 中运行时不会读取的 source map 和 TypeScript 声明文件，不缩小 `asarUnpack` 范围，也不裁剪 JavaScript 运行时。
- 本地构建中，安装器由约 204 MB 降至 181.85 MB，安装后的文件数由 23,048 降至 14,635，安装体积由约 581 MB 降至 489.52 MB。
- Windows 安装 smoke 会输出实际安装耗时和文件数，方便后续持续监控安装性能。

### 本地文件引用

- 内置 `@tokens/dsh-at-file` 更新到 `0.1.1`。
- 非图片文件可拖入整个窗口，拖拽期间显示全屏接收提示。
- 文件路径加入草稿后显示紧凑预览卡片，支持查看文件信息、打开路径和移除引用。
- 目录拖拽和图片拖拽继续交给 Desktop 原有流程处理。

### 模型管理

- 内置 `@tokens/dsh-model-manager` 更新到 `0.2.2`。
- 模型管理页支持编辑并保存 TokensAPI 兼容接口地址，主模型和视觉模型请求统一使用保存后的地址。
- API Key 登录验证仍固定使用 TokensAPI 官方服务，避免自定义推理地址改变凭据验证边界。

### 安全门禁

- 最终包必须保留 Windows x64 的 sharp、ripgrep、koffi、Node addon 和 node-pty 原生文件。
- 最终包必须排除其他平台或 CPU 架构的对应原生文件，以及调试和类型元数据。
- 完整 ASAR 物理镜像、包解析、CLI、诊断 Worker 和插件运行时继续经过构建验收。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Pre-release。
3. 建议先完成一次全新安装，再覆盖安装旧版本，分别确认启动、插件和工具调用正常。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 168 项 Windows 专项测试全部通过。
- 544 个生产依赖的许可证检查通过。
- Electron Builder afterPack 完整物理镜像、包解析和诊断 Worker smoke 通过。
- Windows 最终包验证通过，确认所需 x64 原生运行时存在且其他架构与非运行时元数据已排除。
- Windows amd64 与 macOS arm64、amd64 安装包将由 GitHub Actions 预发布工作流重新构建和校验。

## 已知限制

- 本版本是 Windows 安装性能验证用 Pre-release，不会取代当前稳定版 `latest`。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

# TokensCowork v0.5.0

升级 Desktop 和 DSH 运行时，补齐 RPC 注册与依赖版本适配，并按功能模块整理产品覆盖，方便后续升级时复查和移除已被上游接管的修复。

## 本次更新

- Desktop 固定到 `63e160ab4387988db894adef766865eab897cf80`，DSH 源码固定到 `fb2c4b9e698e30edb738bca4cf0618587db7d203`，运行时使用 `0.1.5-rc.2`。
- 修复新运行时下 Cordis 作用域导致的 RPC 路由注册问题，保留鉴权、显式注销和插件卸载清理。
- 修复压缩将 `ACK` / `STORED` 等无效回复当成摘要替换历史：为摘要调用隔离系统任务，将历史各角色消息作为引用数据，并在替换前验证 checkpoint 格式；不合格时保留原历史。
- 修复固定联网搜索插件的命令描述与新 DSH 接口不兼容、导致 `/` 候选列表报错；仅加工 staging 中的插件产物，本地开发和 CI 共用此适配。
- 补齐初始网页、会话及兼容模式窗口标题的 TokensCowork 品牌；下载页发行类型从固定插件清单生成，避免将带插件的 `0.5.0` 误标为纯净版。
- 隐藏插件市场旁的上游 Agents Anywhere（手机连接）入口；不删除既有连接配置、不卸载其后台组件。
- 修复默认开发目录保留旧压缩补丁时启动被 `Incomplete product compaction adaptation` 阻断：精确识别已知旧 helper 并迁移，兼容 Windows 换行；未知修改仍拒绝，不清理用户数据。
- 产品依赖及对应的市场版本断言跟随固定运行时版本，保留精确版本检查。
- 产品构建收拢为统一入口、流水线步骤和五个覆盖模块；每个模块记录覆盖原因、验证方法与退役条件。
- 内置插件保持当前固定版本；本次没有新增内置插件。

## 已知限制

- 摘要模型仍可能返回不合格内容，现在会拒绝该次压缩并保留历史；格式验证不保证所有语义细节绝不遗漏。原文很短、摘要不比原文小时，上游同样会拒绝，这是正常保护，不应移除。隔离摘要任务会失去普通对话的完整前缀缓存复用，但没有新增模型请求、隐藏重试或修改压缩阈值。
- 真实模型已覆盖独立宿主和已登录 Electron 界面；自动达到产品默认上下文阈值的压缩、真实超长历史与升降级仍未验收，自动触发路径目前使用模拟容量验证。
- Windows 安装包覆盖升级以及 macOS 两种架构的构建、签名、安装与升级尚待 CI / 真机验收。
- 发布输入必须包含与产品声明一致的 Desktop gitlink，并通过产品布局校验；安装包结果以本次 GitHub 工作流为准。
- 不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

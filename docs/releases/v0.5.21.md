## 安装说明

### Windows

1. 下载 Windows amd64 安装器，完全退出正在运行的 TokensCowork。
2. 双击安装器，按提示完成安装。
3. Windows 安装器未进行 Authenticode 签名，可能显示 SmartScreen 提示，请核对来源为本仓库 Release。

### macOS

1. 在“关于本机”中确认处理器类型，选择 Apple Silicon 或 Intel 安装包。
2. 完全退出 TokensCowork，打开 DMG，将应用拖入“应用程序”。
3. 从“应用程序”打开 TokensCowork；如出现首次打开确认，点击“打开”。

两个 macOS 安装包均通过 Developer ID 签名、Apple 公证和票据校验，可按以上步骤正常安装。

## Installation

### Windows Installation

1. Download the Windows amd64 installer and fully quit TokensCowork.
2. Run the installer and follow its instructions.
3. The Windows installer is not Authenticode-signed and may trigger SmartScreen. Verify that it came from this repository's release.

### macOS Installation

1. Check your processor in About This Mac and select the Apple Silicon or Intel installer.
2. Fully quit TokensCowork, open the DMG, and drag the application into Applications.
3. Open TokensCowork from Applications. If the first-launch confirmation appears, click Open.

Both macOS installers passed Developer ID signing, Apple notarization and ticket verification and can be installed using the steps above.

## Known Limitations

- Build duration depends on runners, source checkout, dependency installation and Apple notarization. No overall speed improvement was observed; all three tag-build jobs missed the dependency cache.
- The text guard uses repeated-line thresholds and a character cap and cannot guarantee detection of every semantic loop. IM icon overlap, glass-panel font clarity and the residual Settings outline were not addressed.
- Plugin cards on the English download page retain some Chinese names and descriptions. Gray market cards have not been visually accepted under real-host themes.
- Automated checks do not replace real-model and cross-platform manual installation acceptance. Windows remains unsigned.

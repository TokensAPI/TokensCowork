# TokensCowork v0.5.24

新增浏览器账户登录与生成过程中的重复文本护栏，完善插件市场的安装、更新管理，并修复模型目录同步、搜索取消和更新下载问题。两个 macOS 安装包均已签名并通过 Apple 公证。

## 本次更新

### ✨ 新增功能

- 内置 TokensAPI 账户登录，可在浏览器中完成验证，并按当前账户归属复用或配置模型 API Key，避免使用其他账户遗留的 Key；账户页支持查看、刷新和复制 Key。
- 循环护栏新增生成过程中的重复文本与推理检测，达到重复阈值或字符上限时截断当前文本块，并将截断后的内容保存到会话历史；同一响应中的工具调用继续透传。
- 插件市场支持在“已安装”中统一检查更新、更新和卸载可选插件；内置组件单独展示版本信息，不提供卸载操作。市场目录支持中英文名称与简介，并按账户及组织授权显示可访问的插件。

### 🐛 问题修复

- 修复循环工具调用超过阈值后只阻断一次的问题，后续重复调用持续收到纠正反馈；护栏通知补齐唯一消息 ID 与角色，避免新通知无法持久化或导出。
- 修复启动时后台模型目录刷新后，会话模型列表未同步的问题，更新列表时保留当前模型选择；图片识别失败与模型设置错误按当前界面语言提示。
- 账户会话被服务拒绝时提示重新登录并保留模型 API Key；密钥列表加载失败后可重试，网络和账户业务错误不再误报为会话过期。
- 联网搜索取消后及时结束引擎竞速，不再启动后续引擎；隔离缓存结果，配置变化后清空缓存并阻止旧请求回填。保留引擎原始内容与回退说明，空结果重试提供诊断反馈。
- 更新下载正确处理短写、截断、取消与不安全文件名，清理未完成下载并保留已有安装包；托盘和原生更新弹窗跟随宿主中英文语言。
- 浅色主题关闭文字阴影，修复 IM 会话标题出现重影的问题。

### 🎨 体验优化

- 插件市场默认打开“发现”，已安装插件显示灰色卡片与标识，仍可点击管理；安装或卸载后同步状态。打开已安装可选插件的详情时自动检查更新，失败可重试；“已安装”保留离线管理能力。
- API Key 登录页面明确提示：“仅本次启动有效，退出后需重新验证。保持登录请使用账户登录。”中英文同步。
- 搜索引擎切换使用宿主命令界面与语言服务，明确提示加载、保存或重载失败，并校验时间过滤参数。
- Apple Silicon 和 Intel 的 macOS 安装包均通过 Developer ID 签名与 Apple 公证，拖入“应用程序”后可按正常流程打开。
- 下载页显示所选版本的完整说明，移除重复升级摘要，并修复 GitHub 发布说明的中英文导航。

## What's New

Adds browser-based account sign-in and a guard against repetitive text during generation, improves plugin installation and update management, and fixes model catalog synchronization, search cancellation and update downloads. Both macOS installers are signed and notarized by Apple.

### ✨ New Features

- Bundles TokensAPI account sign-in through your browser. Model API keys are reused or configured for the current account rather than inherited from another account; the account page supports listing, refreshing and copying keys.
- Detects repetitive text and reasoning during generation. When repetition thresholds or the character cap are reached, truncates the current block and saves the truncated content to session history; tool calls in the same response continue to pass through.
- Manage optional plugins from Installed, including update checks, updates and uninstallation. Bundled components display their versions separately without uninstall controls. The catalog supports bilingual names and descriptions and filters access by account and organization grants.

### 🐛 Bug Fixes

- Repeated tool calls continue receiving corrective feedback after reaching the threshold. Guard notifications include unique message IDs and roles so new notifications can be persisted and exported.
- Synchronizes the session model list after background startup catalog refresh while preserving the selected model. Image-recognition and model-setting errors follow the current interface language.
- Prompts for sign-in when an account session is rejected while preserving the model API key. Key-list failures can be retried; network and account business errors are no longer reported as expired sessions.
- Search cancellation promptly ends engine races without starting further engines. Cached results are isolated, settings changes clear the cache and stale requests cannot repopulate it. Original engine content and fallback notices are preserved; empty-result retries provide diagnostics.
- Update downloads handle short writes, truncation, cancellation and unsafe filenames, removing incomplete downloads while preserving existing installers. Tray items and native update dialogs follow the host language.
- Removes light-theme text shadows that caused ghosted IM session titles.

### 🎨 Improvements

- The market opens on Discover. Installed plugins have gray cards and badges and remain accessible for management; installation and removal refresh their status. Opening an installed optional plugin's details automatically checks for updates, with retry on failure. Installed retains offline management.
- API key sign-in now clearly states: "Valid for this launch only. You'll need to verify again after quitting. Use account sign-in to stay signed in." The notice is available in both languages.
- Search engine selection uses the host command UI and language service, reports load, save and reload failures, and validates time filters.
- Apple Silicon and Intel macOS installers pass Developer ID signing and Apple notarization. Drag the application into Applications and open it normally.
- The download page displays the selected version's complete notes without a duplicate upgrade summary; bilingual navigation in GitHub release notes is fixed.

## Installation

### Windows Installation

1. Download the Windows amd64 installer and fully quit TokensCowork.
2. Run the installer and follow its instructions.
3. The Windows installer is not Authenticode-signed and may trigger SmartScreen. Verify that it came from this repository's release.

### macOS Installation

1. Check your processor in About This Mac and select the Apple Silicon or Intel installer.
2. Fully quit TokensCowork, open the DMG, and drag the application into Applications.
3. Open TokensCowork from Applications. If the first-launch confirmation appears, click Open.

Both macOS packages passed Developer ID signing, Apple notarization and ticket validation. Install them using the steps above.

## Known Limitations

- All three platforms used cold caches. Default-branch caches are now populated, but cross-version hits and their benefit remain unverified. Total duration fell by about 14.7%, including runner, packaging and notarization variation; the entire reduction cannot be attributed to compilation changes. Earlier plugin regression ran alongside packaging, so skipping it mainly saves CI resources.
- The text guard uses repeated-line thresholds and a character cap and cannot guarantee detection of every semantic loop. IM icon overlap, glass-panel font clarity and the residual Settings outline were not addressed.
- Plugin cards on the English download page retain some Chinese names and descriptions. Gray market cards have not been visually accepted under real-host themes.
- Automated checks do not replace real-model and cross-platform manual installation acceptance. Windows remains unsigned.

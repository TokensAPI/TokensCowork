# TokensCowork v0.7.14

在 v0.7.13 基础上，Tokens Cowork UI 升级到 0.2.29，界面品牌与主题选项随新标志一起刷新；插件市场新增插件文档中心入口，「可更新」状态改用蓝色；会话日志开关注明只对组织用户有效。

## 本次更新

### 🚀 新功能

- 插件市场接入插件文档中心：右上角「当前教程: TokensCowork」和卡片底部「教程: TokensCowork」点开后，在浏览器里打开插件文档中心，卡片会直接打开该插件那一页；能用当前 Key 换到一次性登录码时自动登录，换不到时照常打开、由你手动登录。
- 插件卡片显示插件图标，开着代理（fake-IP）时图标也能正常加载。

### ⚠️ 其他变更

- Tokens Cowork UI 升级到 0.2.29：侧栏品牌、运行状态和启动画面换上新标志，主题选项随之更新。
- 插件市场「可更新」改用蓝色（右上角刷新图标和底部标签），和绿色的「可安装」、灰色的「已安装」区分开，浅色与深色主题都清楚。
- 会话日志上传开关的说明注明「仅对组织用户有效」（会话日志插件 0.1.3），开关位置和行为不变。
- 产品版本使用 v0.7.14，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🚀 New Features

- The plugin market links to the plugin documentation center: "Current guide: TokensCowork" at the top right and "Guide: TokensCowork" at the bottom of each card open the documentation center in the browser, and a card opens its plugin's page; when the current key can be exchanged for a one-time sign-in code you are signed in automatically, otherwise the page opens and you sign in yourself.
- Plugin cards show plugin icons, which also load when a fake-IP proxy is on.

### ⚠️ Other Changes

- Tokens Cowork UI moves to 0.2.29: the sidebar brand, running status and startup screen use the new mark, and the theme choices are refreshed.
- The market's "Update available" state is now blue (the refresh icon at the top right and the label at the bottom), distinct from the green "Available to install" and the grey "Installed", and readable in light and dark themes.
- The session log upload toggle now says it applies to organization members only (session log plugin 0.1.3); its location and behavior are unchanged.
- The product version is v0.7.14 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

Tokens Cowork UI 0.2.29: the release package's SHA-256 matches the pin, no overlay takes this plugin as input, and the `--theme-info` variable used by the market's "Update available" state is still provided in light and dark for every theme. Market docs entry and icons: tsc passes on a temporary staging and vitest passes 360 cases with 9 skipped. Blue "Update available": 60 market overlay tests pass and light and dark screenshots of the dev build were checked. Session log 0.1.3: plugin tests have no failures and 9 host contract tests pass. Build-code regression passes and the overlay registry check found no drift. Installation and interface acceptance of the v0.7.14 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.13: the Store edition is not listed yet and its built-in TokensCowork updater still checks GitHub releases like the EXE edition; downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request.

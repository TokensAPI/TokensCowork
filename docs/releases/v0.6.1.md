# TokensCowork v0.6.1

在 v0.6.0 基础上把安装包体积减半：剔除打包时混入的另一个处理器架构的原生依赖，并修正 macOS 单架构打包与签名流程；应用功能、内置组件与 v0.6.0 完全相同。

## 本次更新

### 🐛 问题修复

- 安装包不再携带另一个处理器架构的原生依赖（文档转换、Python 运行时、语音识别、图像处理等组件各有 x64 与 arm64 两套，v0.6.0 每个安装包都带了两套）。macOS 安装包由约 396 MB 降到约 200 MB，Windows 安装包由约 256 MB 降到约 130 MB，下载、安装与启动时的签名校验随之加快。
- 修正 macOS 单架构打包：恢复捆绑的 Python 运行时（uv）执行权限，并按上游新位置提供签名所需的 entitlements 清单；v0.6.0 之前的几次发布尝试因此失败。

### ⚠️ 其他变更

- 发布流程按打包目标剔除异架构原生依赖，剔除清单直接取自上游维护的架构文件列表，上游新增原生组件时自动跟随。
- 打包校验同时支持上游新的目录布局与旧的 asar 布局；发布缓存每周自动预热，缩短发版时间。
- 产品版本使用 v0.6.1，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.6.0 相同。

## 验证结果

- v0.6.0 的三平台安装包已由发布流程生成，macOS 两个架构的签名与 Apple 公证通过；v0.6.1 只改变安装包内容，不改变应用代码。
- 构建代码回归 117 项通过；剔除规则对上游架构文件列表的推导、uv 校验按架构过滤、打包校验的两种布局均有用例覆盖；本地按 arm64 目标装配确认 13 个 x64 原生目录进入排除列表。
- 尚未在真实设备上执行 v0.6.1 安装包的安装、账户登录与模型对话验收。

## 已知限制

- 通过 TokensAPI 使用 gpt 系列模型时，上游渠道目前只接受 Codex 客户端，发送消息会失败（界面显示为 “API key is invalid”）；待 TokensAPI 侧调整后恢复，其他模型不受影响。
- 部分插件市场插件需更新到兼容 DSH 0.2 的版本后才能在 0.6 上启用；旧版本会被自动停用，在插件市场更新即可。
- 升级会迁移设置与会话格式，降级回 0.5.x 会丢失这部分设置和会话的显示。
- 固定插件在真实宿主上的交互行为与上游新增能力仍需逐项验收。

## What's New

### 🐛 Bug Fixes

- Installers no longer carry native dependencies for the other processor architecture (document conversion, the Python runtime, speech recognition and image processing each ship x64 and arm64 builds, and every v0.6.0 installer included both). macOS installers shrink from about 396 MB to about 200 MB and the Windows installer from about 256 MB to about 130 MB; downloads, installation and launch-time signature checks are faster.
- Fixed single-architecture macOS packaging: the bundled Python runtime (uv) is executable again and the entitlements file required for signing is provided at its new upstream location; earlier release attempts before v0.6.0 failed on both.

### ⚠️ Other Changes

- The release pipeline prunes foreign-architecture native dependencies per packaging target, deriving the list from the architecture file list maintained upstream so new native components are followed automatically.
- Package verification supports both the new upstream directory layout and the previous asar layout; release caches are warmed weekly to shorten release times.
- The product version is v0.6.1 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.6.0.

## Installation

Choose the DMG matching your processor and drag the app into Applications. The app is signed by the release pipeline and notarized by Apple.

## Verification

The v0.6.0 installers for all three platforms were produced by the release pipeline, with signing and Apple notarization passing for both macOS architectures; v0.6.1 changes only installer contents, not application code. Build-code regression passed 117 tests, including the pruning rule derived from the upstream architecture list, the architecture-filtered uv check and both package layouts; a local arm64 assembly confirmed 13 x64 native directories enter the exclusion list. Installation of the v0.6.1 installers and interactive account/model checks on real devices have not been verified yet.

## Known Limitations

GPT models via TokensAPI currently fail to send because the upstream channel only accepts the Codex client (shown as "API key is invalid"); other models are unaffected. Some plugin-market plugins must be updated to DSH 0.2-compatible versions before they can be enabled on 0.6; older versions are disabled automatically and can be updated from the plugin market. Upgrading migrates settings and session formats; downgrading to 0.5.x loses the display of those settings and sessions. Real-host plugin behavior and newly added upstream capabilities still require item-by-item verification.

# TokensHarness v0.2.2

本版本更新内置的 TokensHarness 版本更新插件，优化稳定版本识别与更新元数据读取，减少客户端直接访问 GitHub API 时遇到的限流问题。

## 本次更新

### 更新检测

- 内置 `@tokens/dsh-version-updates` 0.1.0，固定到提交 `a55243dcf0574a255573c664a96057f1b208c8ad`。
- 优先从 TokensHarness GitHub Pages 的 `releases.json` 读取公开 Release 列表，仅在索引不可用或内容无效时降级到 GitHub latest Release API。
- 仅把 GitHub 原生元数据中 `draft: false` 且 `prerelease: false` 的版本视为稳定版，并从列表中选择最高的稳定 SemVer。
- Release 索引与 API 地址支持通过插件配置覆盖；无效或非 HTTPS 配置会安全回退到默认地址。

### 发布同步

- 下载页会根据 GitHub Release 的 draft 与 prerelease 状态生成版本索引。
- 新建、发布、编辑、切换预发布状态或删除 Release 后，可手动运行 `Deploy Download Page` 同步索引。
- 移除不可靠的定时轮询，避免 GitHub Actions 调度延迟造成状态判断混乱。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.2.2-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.2.2-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.2.2-macos-amd64-installer.dmg` |

正式安装包仅从本仓库的 `v0.2.2` GitHub Release 下载，并使用同一 Release 中的 `TokensHarness-0.2.2-SHA256SUMS.txt` 校验。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库正式 Release。
3. 安装完成后重新启动 TokensHarness，内置更新插件会继续检查后续稳定版本。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 版本更新插件独立测试共 176 条，全部通过。
- 产品布局校验确认只内置 `tokens-version-updates`，并固定到目标插件提交。
- 发布流程会校验版本元数据、发布说明、插件固定提交及完整产品布局。
- Windows amd64、macOS arm64 与 macOS amd64 全部成功后才创建稳定 Release。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 修改现有 GitHub Release 的预发布状态后，需要手动运行 `Deploy Download Page` 更新 Pages 索引；CDN 缓存可能短暂延迟。

# TokensHarness v0.3.6

本预发布版本修复新版侧栏同时显示插件市场与产品更新入口时的布局错位，用于跨平台验证更新按钮在宽侧栏和折叠侧栏中的位置与下载交互。

## 本次更新

### 侧栏布局修复

- 内置 `@tokens/dsh-version-updates` 0.1.0，固定到提交 `90251f448dbd302e68c464d7528848ada7a77e1a`。
- 修复插件市场占满 footer action 行后，更新按钮容器被压缩到零宽并跑到侧栏左侧的问题。
- 宽侧栏中，插件市场继续独占一行；更新版本与小型下载图标固定显示在下一行“设置”的右侧。
- 折叠侧栏中的 footer actions 改为纵向排列，避免多个圆形入口互相挤压或被裁切。

### 回归保护

- 新增侧栏 footer 多入口布局回归测试，约束更新入口不再占用插件市场的正常行宽。
- 重新生成插件客户端运行时产物，保证正式打包直接使用修复后的样式。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.3.6-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.3.6-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.3.6-macos-amd64-installer.dmg` |

本版本作为 GitHub Pre-release 发布，不会被稳定版自动更新检测选中，适合手动下载安装验证。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Pre-release。
3. 可直接覆盖安装旧版本，启动后重点检查插件市场、设置和更新入口的相对位置。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 版本更新插件类型检查、客户端构建和 177 项测试全部通过。
- 产品布局校验会确认插件 Gitlink、`product.json` 固定提交和版本元数据完全一致。
- Windows amd64 构建包含完整产品门禁与静默安装 smoke。
- macOS arm64 与 macOS amd64 分别执行架构、签名和 DMG 完整性校验。

## 已知限制

- 本版本为预发布测试版，不会提示稳定版用户自动更新。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

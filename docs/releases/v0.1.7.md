# TokensHarness v0.1.7

本版本将飞书连接插件加入默认桌面产品，并基于当前固定的桌面、模型管理、版本更新和飞书连接插件提交生成 Windows 与 macOS 安装包。

## 本次更新

### 新增

- 默认内置 `@tokens/feishu` 0.1.1，安装 TokensHarness 后即可配置和使用飞书连接能力。
- 飞书连接插件使用统一的 `tokens-feishu-connect` 产品标识。

### 修复

- 飞书连接插件正式采用 MIT License，并随源码提供完整许可证文本，满足桌面产品的再分发许可证门禁。
- 将飞书连接插件固定到提交 `6723843c91cb01106592f2a868a136da024a9dd9`，确保构建输入可审计且可复现。

### 构建

- 产品锁文件包含飞书连接插件的生产运行依赖，Windows 与两个 macOS 架构使用相同的固定依赖图。
- 保持版本更新插件提交 `7d112a198858e140a9bd6f88b56e550059fba605` 和模型管理插件提交 `c4a39e7a2199678ca4bc1854c17e7b1f2e4adc61`。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.7-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.7-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.7-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- 发布工作流校验产品版本、固定的子模块提交、运行时闭包、许可证和产品品牌。
- Windows amd64、macOS arm64 与 macOS amd64 使用同一 `0.1.7` 版本和 Git commit 构建。
- macOS 构建验证应用架构、代码签名状态与 DMG 完整性。
- 发布成功后统一生成三个安装包的 SHA-256 校验文件。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 飞书连接功能需要用户自行提供有效的飞书应用配置。
- 模型路由请求 TokensAPI 需要有效的 `TOKENSAPI_API_KEY` 凭据。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器，完全退出正在运行的 TokensCowork。
2. 双击安装器，按提示完成安装。
3. 签名及系统提示：Windows 安装器未进行 Authenticode 签名，可能显示 SmartScreen 提示，请核对来源为本仓库 Release。

### macOS

1. 在“关于本机”中确认处理器类型，选择 Apple Silicon 或 Intel 安装包。
2. 完全退出 TokensCowork，打开 DMG，将应用拖入“应用程序”。
3. 首次打开及签名、公证状态：本次配置 Developer ID 签名和 Apple 公证；两个架构的实际签名、公证状态待 CI 构建验证，请以最终构建记录为准。

### 从旧版本升级

- 数据与配置保留情况：覆盖安装保留原有用户配置和会话；真实跨平台数据保留尚未人工验收。
- 需要执行的迁移或兼容性操作：此次无需手动迁移配置。
- 插件升级、重启或重新授权要求：完全退出应用后安装并重新启动，以加载新的内置组件。账户会话过期时按提示重新登录；API Key 临时登录的重启行为保持原设计。

## Installation

### Windows Installation

1. Download the Windows amd64 installer and fully quit TokensCowork.
2. Run the installer and follow its instructions.
3. Signing status and system prompts: The Windows installer is not Authenticode-signed and may trigger SmartScreen. Verify that it came from this repository’s release.

### macOS Installation

1. Check your processor in About This Mac and select the Apple Silicon or Intel installer.
2. Fully quit TokensCowork, open the DMG, and drag the application into Applications.
3. First launch, signing and notarization: Developer ID signing and Apple notarization are configured. Actual signing and notarization for both architectures remain pending CI verification; consult the final build record.

### Upgrading from an Earlier Version

- Data and configuration retention: Installing over the existing application preserves configuration and sessions; cross-platform data retention has not been manually verified.
- Required migration or compatibility steps: No manual configuration migration is required for this update.
- Plugin updates, restarts or reauthorization: Fully quit the application before installation, then restart to load updated bundled components. Sign in again if the account session expires; temporary API-key sign-in retains its existing restart behavior.

## Known Limitations

- The text guard uses repeated-line thresholds and a character cap and cannot guarantee detection of every semantic loop. IM icon overlap, glass-panel font clarity and the residual Settings outline remain unresolved.

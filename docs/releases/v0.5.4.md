# TokensCowork v0.5.4

加快插件市场已安装列表显示，保留后台更新检查，并修复发布版本与生成清单不同步的问题。

## 本次更新

- 本地插件列表先显示，再后台检查更新；失败时保留列表并允许重试。
- 复用已授权目录中的有效版本提示，缺失时回退查询，更新前仍验证权限及包信息。
- 版本同步脚本自动生成市场清单，并在版本检查时校验一致性。
- 补齐 0.5.3 构建失败时遗漏的生成清单，不改变上游与内置插件固定版本。

## 下载说明

附件以上传成功的构建结果为准。

- Windows amd64：`TokensCowork-0.5.4-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.4-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.4-macos-amd64-installer.dmg`

## 安装说明

退出应用后覆盖安装，建议提前备份用户数据，无需删除原配置。

## 验证结果

- 市场加载优化已完成本地验证；界面及 API 测试 50 项通过、1 项原有跳过。
- 生成清单与产品版本重新同步；安装包及跨平台验证以本次 CI 结果为准。

0.5.3 未生成安装包。此版本不包含服务端缓存改动，不部署市场服务；更新检查仍受网络可用性影响。

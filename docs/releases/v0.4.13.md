# TokensCowork v0.4.13

修复自建来源插件安装前错误访问公开 npm 的验证问题，并修正下载凭证参数与第三方依赖的安装来源。

## 本次更新

- 组合验证器完整传递自建仓库类型与插件 ID，不再把已撤下公开 npm 的包送到错误来源验证。
- 修正生成代码中的 API Key 正则转义和 pnpm 鉴权参数格式。
- 自建仓库的公开插件允许匿名下载，不再强制要求配置 API Key。
- 对当前作用域插件，第三方依赖保留公开 npm 来源，避免向单插件授权入口请求其他包。
- 上游 Desktop、Harness 和内置插件固定提交不变。

## 下载说明

此 Release 用作预发布验证。构建成功后下载对应的 Windows amd64 或 macOS arm64 / amd64 安装包，核对同页 SHA256 文件。

## 安装说明

- 完全退出应用后覆盖安装，保留原有用户数据。
- 打开市场重新检查插件，在插件详情中验证安装。
- 受限插件仍要求组织或单独 API Key 授权，内部仓库账号不提供给最终用户。

## 验证结果

- 重新装配客户端后，本地全量测试 272 项通过、9 项跳过。
- 真实组合验证器回归测试覆盖自建来源身份传递；安装参数测试覆盖匿名和携带 Key 的场景。
- 在隔离 Profile 中，通过修复后的安装服务及桌面自带 pnpm，完成线上插件体检 0.4.0 的验证、下载、安装、Profile 登记和卸载。
- 真实安装分别验证无 Key 和携带测试鉴权参数的公开包下载；未用该测试宣称受限组织授权已通过。
- 隔离测试禁用了生命周期脚本及宿主 peer 依赖自动安装，未启动插件或调用模型。
- 跨平台完整构建及许可证门禁由 Build Desktop 验证。

## 已知限制

- 尚未完成安装包在真实应用界面中的插件启用、更新及受限组织授权全流程人工验收。
- 私有同作用域依赖、无作用域私有插件的复杂依赖图未纳入此次真实安装测试。
- Windows 安装器未签名，可能显示 SmartScreen 提示。
- 已下载副本不能收回；公开 npm 已撤包的插件不再支持旧客户端原路径安装。

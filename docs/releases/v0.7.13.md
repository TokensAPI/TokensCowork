# TokensCowork v0.7.13

在 v0.7.12 基础上，会话可以从右键菜单永久删除；插件市场改从侧栏「插件」一行打开；应用、下载页与市场后台换上新图标和字体；会话日志只上传组织成员的日志；模型下拉里不再出现 OCR 模型。

## 本次更新

### 🚀 新功能

- 会话可以永久删除：在会话上右键（或点行尾「…」）选「删除」，确认后会话和它的全部记录（包括附件和它派生的子 Agent 会话）从电脑上删除，不能恢复。正在运行的会话会先停止再删除；15 秒内停不下来时只归档、不删除，稍后可以再删。只有本机窗口能删除，远程控制和局域网访问不能删除。
- 插件市场从侧栏上方的「插件」一行打开，在右侧主区域显示，内容与原来的市场浮层相同（发现、已安装、来源）；侧栏底部不再有单独的市场入口。市场里的时间按本地时区显示。

### ⚠️ 其他变更

- 换用新图标：应用、托盘、安装包与 Microsoft Store 图标改为白底圆角的新图形，产品名仍为 TokensCowork；下载页与市场后台同步换上新标志和 Quicksand 字体。
- 会话日志只上传组织成员的日志：每次上传前向 TokensAPI 查询当前账号是否属于某个组织，属于才上传；不属于组织、手动填写密钥未登录或查询失败时都不上传。
- TokensAPI 模型插件升级到 0.2.30：OCR 一类模型不再出现在设置页下拉、输入框模型菜单和视觉模型候选里。
- 构建时下载内置插件包遇到 GitHub 临时错误会自动重试。
- 产品版本使用 v0.7.13，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🚀 New Features

- Sessions can be deleted permanently: right-click a session (or use the row's "…" menu), choose Delete and confirm; the session and all its records, including attachments and the subagent sessions it spawned, are removed from the computer and cannot be restored. A running session is stopped first; if it does not stop within 15 seconds it is only archived and can be deleted later. Only local windows can delete; remote control and LAN access cannot.
- The plugin market opens from the Plugins row at the top of the sidebar and shows in the main area with the same content as the old market overlay (Discover, Installed, Sources); the separate market launcher at the bottom of the sidebar is gone. Times in the market use the local time zone.

### ⚠️ Other Changes

- New icon: the app, tray, installer and Microsoft Store icons use the new mark on a white rounded tile, and the product name stays TokensCowork; the download page and the market admin console use the new mark and the Quicksand font.
- Session logs are uploaded only for organization members: before each upload the plugin asks TokensAPI whether the current account belongs to an organization, and uploads only if it does; accounts outside an organization, manually entered keys without a login, and failed lookups upload nothing.
- The TokensAPI model plugin moves to 0.2.30: OCR models no longer appear in the settings drop-down, the composer model menu or the vision model candidates.
- Downloads of bundled plugin packages during the build retry on transient GitHub errors.
- The product version is v0.7.13 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

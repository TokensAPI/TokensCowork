# TokensHarness v0.3.5

本版本将 v0.3.2 至 v0.3.4 已完成跨平台验证的功能提升为稳定版，基于 v0.3.1 稳定版增加本地文件引用、正式品牌 Logo、模型管理更新和 Windows 安装优化。

## 本次更新

### 产品功能

- 新增并默认启用 `@tokens/dsh-at-file` 0.1.1，支持选择或拖入非图片文件，并以预览卡片管理当前草稿中的本地路径引用。
- `@tokens/dsh-model-manager` 更新到 0.2.2，支持保存 TokensAPI 兼容接口地址，并统一主模型和视觉模型请求地址。
- 保留版本更新、飞书连接、模型管理和本地文件引用共 4 个已验证默认插件。

### 正式品牌

- Windows、macOS、系统托盘、网页 favicon 和客户端界面统一使用 TokensHarness 正式 Logo。
- 品牌资源只在 staging 中注入，不修改只读 Desktop、DSH 或插件子模块。

### Windows 安装优化

- Windows amd64 安装包排除其他平台和 CPU 架构的原生二进制文件。
- 移除运行时不会读取的 source map 和 TypeScript 声明，同时保留完整 JavaScript、CLI、Loader、Worker、Profile 和插件运行时。
- 安装 smoke 会验证静默安装完成、文件数量和 `TokensHarness.exe` 是否存在。

### 构建流程

- Windows 的完整产品门禁与安装包复用同一份 staging，不再重复运行独立 Desktop 质量构建。
- Windows、macOS Apple Silicon 和 macOS Intel 仍在同一次 `Build Desktop` 工作流中并行构建，全部通过后统一发布。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.3.5-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.3.5-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.3.5-macos-amd64-installer.dmg` |

安装包及 SHA-256 校验文件仅从本仓库 `v0.3.5` GitHub Release 下载。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Release。
3. 可直接覆盖安装旧版本；首次升级建议确认启动、插件和常用工具调用正常。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- Market 19 个测试文件、274 项测试全部通过。
- 168 项 Windows 专项测试和 544 个生产依赖许可证检查通过。
- Desktop 类型、CLI、Loader、Profile、品牌和运行时闭包检查通过。
- Windows 最终包、Electron Builder afterPack、诊断 Worker 和静默安装 smoke 通过。
- Windows amd64、macOS arm64 和 macOS amd64 由同一次正式工作流重新构建并校验。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 本地文件引用传递文件路径，具体文件格式能否解析取决于当前会话可用工具。

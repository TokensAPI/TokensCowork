# TokensHarness v0.3.2

本版本在 v0.3.1 的稳定 Desktop 与 DSH 基线上新增本地文件引用能力，让用户可以像 Codex 一样选择或拖入文件，并把绝对路径交给当前会话的工具读取。

## 本次更新

### 产品插件

- 新增并默认启用 `@tokens/dsh-at-file` 0.1.0，插件实例名称为 `tokens-at-file`。
- 支持通过 Desktop 回形针按钮一次选择一个或多个本地文件。
- 支持把非图片文件拖入输入框；纯图片仍使用 DSH 原生图片附件流程。
- 保留原有工作区 `@path` 搜索、引用、打开和过滤能力。

### 文件处理边界

- 插件不上传、不复制也不转换文件，只把用户选择文件的绝对路径加入输入内容。
- 文件扩展名不受限制；PDF、Excel、压缩包和其他格式能否解析取决于当前会话可用的工具。
- 普通 Web 浏览器不暴露本地文件路径桥接，因此本地选择按钮只在兼容的 Desktop 中显示。

### 稳定基线

- 保持 Verified DSH Desktop 提交 `d457d790295e727bbb1fc20e398da602f521fd64`。
- 保持 DeepSeek Harness 提交 `141eb6fef83422698aef7a981029e843e8161534`（`0.1.0-rc.8`）。
- 默认产品插件数量从 3 个增加到 4 个。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Release。
3. 启动后可直接使用输入框回形针选择文件，或拖入非图片文件。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 插件类型检查、构建与测试通过；Windows 环境执行 170 项测试，3 项仅适用于支持符号链接的平台而跳过。
- 产品布局检查确认 Desktop、嵌套 DSH 与 4 个默认插件均固定到指定提交。
- 生产依赖许可证门禁检查 544 个包并通过。
- Windows amd64 与 macOS 安装包由正式发布工作流分平台构建并校验。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 插件传递的是文件路径，不保证当前模型或 Agent 一定具备解析所有二进制格式的工具。

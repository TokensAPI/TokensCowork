# TokensCowork v0.4.3

将插件市场确立为产品的常驻能力：新老用户的市场入口永久可用，历史上被崩溃恢复流程误关的安装在升级后首次启动即自动复原。

## 本次更新

### 功能变化

- 插件市场提供方固定为社区市场：正常启动时凡持久记录不是社区市场（含历史版本崩溃恢复流程以“显式关闭”写入的记录）一律自动纠正，机器状态与 Profile 偏好两处同时复原。Safe Mode 诊断会话不受影响。
- 语义说明：市场从本版本起为产品常驻能力。设置中切走市场提供方只对当次运行生效，下次启动即复原。

### 背景

- v0.4.x 之前的崩溃恢复路径会把“市场关闭”以显式选择的形式写盘，与用户手动关闭在数据上无法区分；被误关的用户没有任何提示，市场入口永久消失。v0.4.2 的“默认开启”只覆盖从未选择过的全新安装，本版本将老用户一并纳入。

请从本仓库 Release 页面下载对应系统与架构的安装包，并使用同页校验文件核对完整性。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 市场固定覆盖经 Desktop 工作区完整类型检查；启动纠正只在正常启动路径执行，Safe Mode 与首启默认路径行为不变。
- 产品布局、版本钉定、市场名册一致性与快照闸门全部通过。
- 完整的桌面与市场测试套件、运行时闭包、许可证门禁与预设健康检查补丁验收由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

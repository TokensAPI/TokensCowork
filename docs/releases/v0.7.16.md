# TokensCowork v0.7.16

相对 v0.5.25 汇总 v0.6.0 至 v0.7.16 的全部更新：内核从 Desktop 2.0.9 / DSH 0.1.5-rc.2 升级到 Desktop 2.0.18 / DSH 0.2.1-rc.2；随包提供 Python/Node 运行时与 Office 技能；自动化并入计划任务页，主题按组织自动应用；插件市场、模型列表、会话管理与更新检查全面改进。升级会迁移设置与会话格式，升级后不支持回退到 0.5.x。

## 本次更新

### ⚠️ 从 0.5.x 升级须知

- 内核从 Desktop 2.0.9 / DSH 0.1.5-rc.2 升级到 Desktop 2.0.18 / DSH 0.2.1-rc.2。
- 首次启动时，设置会迁移到新的存储格式，原设置文件备份为 `~/.dsh/settings.yaml.imported`；旧会话照常显示在列表里，打开时自动转换成新格式，聊天记录不会丢失。
- 升级后不支持回退到 0.5.x：旧版本读不到迁移后的模型配置、主题、语言和市场记录，也不显示已转换的会话。
- 部分插件市场插件需要更新到兼容新内核的版本才能启用；旧版本会被自动停用，在插件市场更新即可。

### 🚀 新功能

- 随安装包提供 Python 与 Node 运行时和 Office 技能，开箱即可处理文档、表格与演示文稿。
- 自动化并入内核自带的计划任务页；首次启动时，旧的自动化任务会自动迁移过去。
- 主题按 API Key 所属组织自动应用，新增多款合作方主题，也可以在主题选择里手动切换。
- 会话可以从右键菜单永久删除。
- 「检查更新」弹窗会显示新版本改了什么。
- 新增内置插件「会话日志上传」：组织成员使用 TokensAPI 时，会话日志在后台上传，用于改进模型与产品。
- 插件市场：从侧栏「插件」打开，默认显示「发现」页；卡片直接标出可安装、已安装、可更新状态；新增插件文档中心入口；插件热更新无法替换已加载的依赖时，会提示重启并提供一键重启。

### 🔧 改进

- 安装包体积减少约四分之一，安装后的应用目录减少约三分之一。
- 模型列表只保留能用于对话的模型并按厂商排序；正在用的模型下线时，自动换回默认模型并提示；新用户默认使用 deepseek-v4-flash-vision-exp；API Key 通过登录等途径写入后，模型列表与路由立即刷新。
- 模型的上下文长度以 TokensAPI 返回的值为准，上下文压缩按这个长度计算。
- 插件市场只在打开时检查一次更新，「发现」、插件详情和「已安装」共用这次的结果；「发现」页先显示缓存，网络请求快速失败，不再长时间转圈。
- 一轮任务执行中的状态行显示「正在思考中」；会话运行中的状态图标更省 CPU；设置里的「账户管理」页与相邻页面使用同一套结构。
- 应用、下载页与插件市场换上新图标和字体。

### ⚠️ 其他变更

- 侧栏「插件」页只保留 TokensCowork 自己的插件市场，不再显示上游市场、来源配置与远程控制入口。
- 会话日志只上传组织成员的日志，设置里不再显示上传开关。
- 产品版本为 v0.7.16，作为 GitHub 正式版发布。

## What's New

### ⚠️ Upgrading from 0.5.x

- The runtime moves from Desktop 2.0.9 / DSH 0.1.5-rc.2 to Desktop 2.0.18 / DSH 0.2.1-rc.2.
- On first launch, settings migrate to the new storage format and the original settings file is kept as `~/.dsh/settings.yaml.imported`. Existing sessions stay in the list and are converted to the new format when opened, so no chat history is lost.
- Downgrading to 0.5.x afterwards is not supported: it cannot read the migrated model configuration, theme, language and market records, and does not list converted sessions.
- Some plugin-market plugins need a version compatible with the new runtime before they can be enabled; older versions are disabled automatically and can be updated from the plugin market.

### 🚀 New Features

- Python and Node runtimes and the Office skills ship with the installer, so documents, spreadsheets and presentations work out of the box.
- Automations move into the runtime's built-in scheduled-task page; existing automations are migrated on first launch.
- Themes follow the organization of the API Key automatically, with several new partner themes, and can still be picked by hand.
- Sessions can be deleted permanently from the context menu.
- The "Check for updates" dialog shows what changed in the new version.
- New built-in "Session Log Upload" plugin: when organization members use TokensAPI, session logs are uploaded in the background to improve models and the product.
- Plugin market: opened from the sidebar's "Plugins" row with Discover as the default view; cards show installable, installed and updatable states; a link to the plugin documentation center; when a hot update cannot replace an already-loaded dependency, it asks for a restart with a one-click restart button.

### 🔧 Improvements

- Installers are about a quarter smaller, and the installed app directory about a third smaller.
- The model list keeps only conversation models, sorted by maker; when the model in use is withdrawn, it switches back to the default with a notice; new users default to deepseek-v4-flash-vision-exp; the model list and route refresh as soon as an API Key is written by sign-in or other means.
- A model's context length follows the value TokensAPI returns, and context compaction uses that length.
- The plugin market checks for updates once when it opens, and Discover, plugin details and Installed share that result; Discover shows the cached catalog first and remote requests fail fast instead of spinning.
- The status line during a run reads "正在思考中"; the running-state icon uses less CPU; Settings → Account uses the same structure as the neighbouring pages.
- New icons and fonts for the app, the download page and the plugin market.

### ⚠️ Other Changes

- The sidebar "Plugins" page shows only the TokensCowork plugin market, without the upstream market, source configuration or remote-control entries.
- Session logs are uploaded only for organization members, and Settings no longer shows an upload toggle.
- The product version is v0.7.16, published as a stable GitHub release.

## Verification

The v0.7.16 installers were built by the release pipeline: the Windows quality gate passed, the macOS installers are signed and notarized by Apple, and the bundled plugins passed the real-runtime contract gate on the assembled runtime. The overlay registry check found no drift, the overlay assembly check reported 91 effective and 0 needing changes, and build-code regression passed 230 cases.

## Known Limitations

Downgrading to 0.5.x loses the display of migrated settings and sessions. Session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request. GPT and Codex models are not usable through TokensAPI for now and are hidden from the model list by default.

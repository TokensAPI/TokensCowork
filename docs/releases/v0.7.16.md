# TokensCowork v0.7.16

在 v0.7.15 基础上，润洲组织自动使用润洲主题与标志，会话运行中的状态图标更省资源（Tokens Cowork UI 0.2.31）。

[中文](#user-content-release-notes-zh) | [English](#user-content-release-notes-en)

<a name="release-notes-zh"></a>

## 本次更新

### 🚀 新功能

- 新增「润洲」合作方主题：组织 ID 为 6 的成员登录后自动使用润洲配色和标志，其他人也可以在主题选择里手动切换到「润洲」。

### 🔧 改进

- 会话运行中的转圈状态点改为整体旋转，不再每一帧重绘图形，长时间运行时占用更少的 CPU；对话区的品牌标志固定使用 TokensCowork 基础标志，不随组织主题变化。

### ⚠️ 其他变更

- 产品版本使用 v0.7.16，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🚀 New Features

- New "Runzhou" partner theme: members of organization 6 get the Runzhou colours and logo automatically after signing in, and anyone can pick "润洲" in the theme menu.

### 🔧 Improvements

- The spinning status dot shown while a conversation runs now rotates as one layer instead of redrawing every frame, using less CPU during long runs; the brand mark in the conversation area always shows the base TokensCowork mark regardless of the organization theme.

### ⚠️ Other Changes

- The product version is v0.7.16 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

Tokens Cowork UI 0.2.31: the package checksum matches the release page; the overlay registry check found no drift, the overlay assembly check reported 91 effective and 0 needing changes, and build-code regression passed 230 cases. Installation and interface acceptance of the v0.7.16 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.15: the Store edition is not listed yet and its built-in TokensCowork updater still checks GitHub releases like the EXE edition; downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request.

## 本次更新

### 🐛 问题修复

- 主模型通过视觉模型读图时，如果识别失败（例如网络抖动或上游临时出错），现在会自动重试 2 次（约 1 秒、3 秒后），不再一次失败就整轮提示「图片识别失败」。失败结果也不再保留 60 秒，重新发送会立刻重新识别。提示语和其余行为不变（TokensAPI 模型插件 0.2.31）。

### ⚠️ 其他变更

- 产品版本使用 v0.7.18，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🐛 Bug Fixes

- When the main model reads an image through the vision model and recognition fails (for example a network blip or a temporary upstream error), it is now retried automatically twice (after about 1 s and 3 s) instead of failing the whole turn with "Image recognition failed". A failed result is no longer held for 60 seconds, so sending again recognizes the image right away. The message and all other behavior are unchanged (TokensAPI Models plugin 0.2.31).

### ⚠️ Other Changes

- The product version is v0.7.18 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

TokensAPI Models plugin 0.2.31: plugin CI passed on Windows, macOS and Linux with Node 22 and 24; 34 real-host contract tests passed; the screenshot from the user report was recognized successfully, and with the network unreachable the read was retried twice before the original message appeared. The overlay registry check found no drift and build-code regression passed. Installation and interface acceptance of the v0.7.18 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.17: downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request; GPT and Codex models are not usable through TokensAPI for now and are hidden from the model list by default.

# TokensCowork v0.3.19

本预发布版本修复 DSH Desktop 在用户 Profile 残留旧内核时可能触发的工具执行崩溃。

## 本次更新

### 修复

- 将 Desktop 自身和 `@deepseek-ai/*` 核心包固定解析到当前安装目录。
- 避免 Profile 中另一份 `dsh-tools` 产生不同的 scheduler `Symbol`，从而导致工具调用出现 `undefined.prepare`。
- 增加模块解析回归门禁，升级应用后无需逐台清理旧 Profile。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.3.19-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensCowork-0.3.19-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensCowork-0.3.19-macos-amd64-installer.dmg` |

本版本默认作为 GitHub Pre-release 发布，验证完成后可在 Release 页面转为稳定版本。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 模块解析回归测试 8 项全部通过。
- Desktop TypeScript 类型检查、真实编译、Loader 启动验证和 Profile 启动验证通过。
- 产品布局检查通过；最终 Windows 安装包由本次发布流程生成。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

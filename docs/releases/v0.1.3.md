# TokensHarness v0.1.3

本版本完成桌面运行时品牌化，确保 Windows 和 macOS 安装后使用 TokensHarness 的窗口标题、用户数据目录和应用身份，并修复 Windows 静默卸载未实际删除应用的问题。

## 本次更新

### 新增

- 新增产品化运行时验证，同时检查生成副本源码、编译产物和 Windows 解包应用。

### 修复

- 修复窗口标题仍显示 `DeepSeek Harness Desktop` 的问题。
- 修复 Electron 用户数据仍写入 `%APPDATA%\DSH Desktop` 的问题。
- 修复 Windows App User Model ID 仍使用上游 `ai.deepseek.dsh.desktop` 的问题。
- 修复产品配置在运行时编译后才注入，导致修复未进入安装包的构建顺序问题。
- 修复 NSIS 静默卸载返回成功但安装目录仍保留的问题。

### 优化

- Windows 辅助安装界面统一使用 TokensHarness 名称。
- 新增 Windows 重复装卸测试命令：默认保留用户数据，只有显式传入 `--purge-data` 才清理配置。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.3-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.3-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.3-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- Windows amd64：桌面构建、类型检查、运行时闭包、许可证门禁与产品品牌验证通过。
- macOS arm64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- macOS amd64：由发布工作流构建并验证架构、签名与 DMG 完整性。
- 三平台产物必须使用同一 `0.1.3` 版本、Git commit 和已公布的 SHA-256。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

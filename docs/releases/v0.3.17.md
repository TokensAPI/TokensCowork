# TokensCowork v0.3.17

本预发布版本收敛插件市场来源配置，确保新旧用户都只看到 TokensAPI 官方来源。

## 本次更新

### 修复

- 产品启动时统一迁移市场来源配置，只保留 TokensAPI 官方来源。
- 清除旧版本保存的其他来源，避免历史配置继续显示在来源列表中。
- 仅调整来源配置，不删除已安装插件及其安装记录。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.3.17-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensCowork-0.3.17-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensCowork-0.3.17-macos-amd64-installer.dmg` |

本版本默认作为 GitHub Pre-release 发布，验证完成后可在 Release 页面转为稳定版本。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据和已安装插件。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- Market 完整测试通过：19 个测试文件，267 项通过，8 项按既有产品策略跳过。

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

## 安装说明

### Windows

完全退出 TokensCowork，再运行 amd64 安装器。安装器未签名，核对仓库及 SHA-256 后安装。

### macOS

按处理器选择 arm64 或 amd64 DMG，将应用拖入"应用程序"。应用由发布流程签名并经 Apple 公证。

## 验证结果

- 与 v0.7.20 同一套代码与内置组件，只改了版本号。
- 尚未在真实设备上执行 v0.7.21 安装包的安装与界面验收；这正是本次演练要做的。

## 已知限制

- 与 v0.7.20 相同：降级回 0.5.x 会丢失迁移后的设置与会话显示；会话日志在每次模型请求前上传，每一轮最后的回答要等这个会话下一次请求时才上传；通过 TokensAPI 使用 GPT 与 Codex 系列模型暂不可用，模型列表默认隐藏这些模型。

## Installation

### Windows Installation

Exit TokensCowork before running the amd64 installer. It is unsigned; verify the repository and SHA-256.

### macOS Installation

Choose the DMG matching your processor and drag the app into Applications. The app is signed by the release pipeline and notarized by Apple.

## Verification

Same code and bundled components as v0.7.20; only the version number changed. Installation and interface acceptance of the v0.7.21 installers on real devices have not been performed yet; that is what this drill is for.

## Known Limitations

Same as v0.7.20: downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request; GPT and Codex models are not usable through TokensAPI for now and are hidden from the model list by default.

# TokensCowork v0.4.9

模型管理器升级至 0.2.18，修复图片计价接口缺失导致的压缩失败，原生多模态模型改为直接请求 TokensAPI，并解除备用线路操作对主线路模型列表的等待依赖。

## 本次更新

- 补齐 DSH 适配器图片计价接口，使旧会话的 token 计量、手动压缩及上下文溢出恢复能够继续执行。
- 原生多模态模型直接使用 TokensAPI；需要图片转文本的模型保留视觉桥接，旧版 ModLens 路由仍兼容。
- 同步会话的 provider 和模型选择，切换原生与桥接模型后保持实际请求与界面一致。
- 已通过本地认证的用户可独立获取、保存及切换备用线路模型；请求超时覆盖响应体，并隔离取消和过期响应。
- Desktop、Harness 和其他内置插件的固定版本不变，生产依赖图不变。

## 下载说明

从本仓库 Release 页面下载 Windows amd64、macOS Apple Silicon（arm64）或 Intel（amd64）对应安装包，并核对同页 SHA256 校验文件。

## 安装说明

- Windows：退出应用后运行安装器，覆盖安装保留用户数据。
- macOS：将 DMG 内的应用拖入“应用程序”并替换旧版。
- 已经超限的旧会话升级后可再次手动压缩。原生直连选择按模型能力声明或已确认的配置决定，不根据名称猜测。

## 验证结果

- 插件全量测试：906 项通过，61 项按当前平台条件跳过；类型检查、代码检查及 Git 分发构建通过。
- 插件 GitHub CI：Windows、macOS、Linux 各在 Node 22.19 和 24 上验证，6 个任务全部通过。
- 对报告的失败会话进行内存隔离回放，使用真实 DSH token-meter 和压缩引擎、离线摘要替身；确认缺失接口错误可复现，修复后的旧路由和直连路由均可完成手动压缩及溢出恢复。
- 合成长历史验证自动压力压缩。原始会话的估算低于默认阈值，按上游策略不提前压缩，超限后由溢出恢复处理。
- 未执行会话里的工具、未调用付费模型，真实网关与各平台安装体验仍需验证。
- Windows、macOS 两架构的完整构建、生产许可证和产物检查交由 Build Desktop；所有构建通过后才发布安装包。

## 已知限制

- 修复不会扩大模型上下文，也不能保证摘要请求在真实网关上一定成功；网络或模型服务故障仍可能中断压缩。
- Windows 安装器未签名，可能提示 SmartScreen；macOS 若采用临时签名而非公证签名，首次启动可能需要在系统设置中放行。
- 不提供 Windows ARM64、32 位或 Linux 安装包。

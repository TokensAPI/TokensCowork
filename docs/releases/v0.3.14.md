# TokensCowork v0.3.14

本预发布版本将产品正式更名为 TokensCowork，插件市场收敛为产品自营目录源并支持从市场一键安装浏览器操作插件。

## 本次更新

### 新增

- 产品更名为 TokensCowork：应用名、安装包、窗口标题、安装器文案与全套品牌视觉同步更新；老用户升级时自动迁移 TokensHarness 的用户数据目录，会话与配置无缝保留。
- 插件市场收敛为产品自营源：TokensAPI 官方目录源随产品预置并默认选中，打开市场即可浏览产品插件，无需手动添加；上游合作源与手动添加入口不再展示。
- 浏览器操作插件（@tokensapi/dsh-browser-use 0.1.0）上架市场：可在市场内一键安装，安装时对 npm 官方 registry 实时核验身份、仓库与完整性。

### 优化

- 构建系统重构：产品覆盖逻辑按主题拆分为独立模块（更新、市场、Windows ACL、桌面运行时、品牌、Windows 安装器），每处覆盖自带锚点守护。
- TokensAPI 模型插件升级到 0.2.13。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 从 TokensHarness 旧版本升级会自动卸载旧版本，用户数据目录自动迁移到 TokensCowork 并保留。
3. 如果旧文件仍被占用，先完全退出应用和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入"应用程序"。
3. 未正式公证的构建首次启动时，需要右键应用并选择"打开"。

## 验证重点

1. 从 TokensHarness 0.3.13 覆盖升级后，应用名与图标为 TokensCowork，历史会话、API Key 与设置全部保留。
2. 打开插件市场即显示 TokensAPI 插件源目录，无需手动添加；不出现上游合作源与"添加标准来源"入口。
3. 市场内一键安装"浏览器操作"插件，重启后浏览器操作功能可用。
4. Windows 受限命令执行正常且无控制台窗口闪现。

## 验证结果

- 市场收敛覆盖经产品构建全量验证：typecheck 通过，市场测试 268 项通过、6 项按产品策略跳过（断言已移除行为的上游用例，均带锚点守护）。
- 用户数据迁移按 legacyNames 顺序执行，重命名失败时降级为复制，不阻断启动。
- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- 受限沙箱基础设施熔断为会话级：触发后需重启会话恢复对应受限模式。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

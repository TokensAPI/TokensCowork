# TokensCowork v0.7.12

在 v0.7.11 基础上，发布流程多出一个 Microsoft Store 商店包（MSIX），为上架 Microsoft Store 做准备；EXE 与 DMG 安装包的功能与 v0.7.11 相同。macOS 安装包改在 GitHub 的 macOS 15 机器上构建。内核与内置插件版本不变。

## 本次更新

### 🚀 新功能

- Windows 新增 Microsoft Store 商店包：和 EXE 用同一份程序打包，包标识与 Partner Center 一致（1FCF6A48.TokensCowork，发布者「杭州欧瑞德林经济咨询有限公司」）。这个包不签名、不放进本页的下载附件，只用来提交 Microsoft Store，商店审核通过后由 Microsoft 签名再发给用户。
- 商店版与 EXE 版读写同一份数据：设置、插件配置与日志都在 `%APPDATA%\TokensCowork`，插件与 Profile 在 `%USERPROFILE%\.dsh`，两个版本互通，外部程序也能打开这些文件。两个版本不会同时运行：已经开着一个时，再打开另一个会切换到已打开的窗口。
- 商店版的任务栏、开始菜单图标使用 TokensCowork 图标，浅色与深色任务栏都不带色块底板。

### ⚠️ 其他变更

- macOS 安装包的构建机器从 GitHub 已停用的 macOS 14 换到 macOS 15，签名、公证与 DMG 打包流程不变。
- 产品版本使用 v0.7.12，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🚀 New Features

- Windows gains a Microsoft Store package (MSIX): it is packed from the same program as the EXE, and its identity matches Partner Center (1FCF6A48.TokensCowork, publisher 杭州欧瑞德林经济咨询有限公司). The package is unsigned and not attached to this release; it is only for Microsoft Store submission, and Microsoft signs it after certification before delivering it to users.
- The Store edition and the EXE edition use the same data: settings, plugin profiles and logs in `%APPDATA%\TokensCowork`, plugins and profiles in `%USERPROFILE%\.dsh`, so both editions share them and other programs can open those files. The two editions never run at the same time: opening one while the other is running switches to the open window.
- The Store edition's taskbar and Start icons use the TokensCowork icon without a colored plate on light and dark taskbars.

### ⚠️ Other Changes

- macOS installers are now built on GitHub's macOS 15 machines instead of the retired macOS 14 ones; signing, notarization and DMG packaging are unchanged.
- The product version is v0.7.12 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

Store package: rehearsal build 42577133351 passed in full; after packing, the build checks the three identity fields, the four-part version format 0.7.12.0, the absence of a self-signature, the full-trust and write-virtualization opt-out declarations, and the icons. The Store package was installed in developer mode on a real Windows 11 machine: every startup stage completed and the interface reported healthy; a folder created inside the Store package context landed in the real `%APPDATA%` (before write virtualization was turned off it was redirected to the Store-private folder); the taskbar icon, window, plugins, terminal commands and desktop file access were checked by hand. On macOS 15 machines, signing, notarization and packaging of the arm64 and amd64 installers passed in the rehearsal build. Build-code regression passed 201 cases and the overlay registry check found no drift. Installation and interface acceptance of the v0.7.12 installers on real devices have not been performed yet.

## Known Limitations

The Store edition is not listed yet; its built-in TokensCowork updater still checks GitHub releases like the EXE edition, and moving it to Microsoft Store updates is in progress, so until then the Store edition is used only for internal submission tests. Same as v0.7.11: downgrading to 0.5.x loses the display of migrated settings and sessions; a failed route save after a model pick reverts the button and logs the reason without a toast; the first open of the market Discover still takes about 1–2 seconds; English release notes in the dialog show highlights but no summary; a very long highlight shows only the whole sentences that fit; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request.

# TokensCowork v0.5.10

修复应用内更新下载经过文本型跨进程桥接导致安装包二进制数据异常的问题，并明确提示更新失败。

## 本次更新

- 更新插件固定到提交 4d06dc81c0259330b26a7c576d025d35ffb2ac8d，安装包通过插件进程直接获取二进制流，保留 SHA-256 校验。
- 下载或启动安装器失败时返回失败状态并提示重试，不再静默失败或误报成功。
- 保留 0.5.9 的循环护栏及已有 Desktop、DSH 与其他插件固定版本。

## 下载说明

以 pre-release 发布，安装包以 GitHub 构建成功后的附件为准。

- Windows amd64：`TokensCowork-0.5.10-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.10-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.10-macos-amd64-installer.dmg`

## 安装说明

完全退出应用后覆盖安装，无需删除用户数据。旧版应用内更新如果失败，请从本发布页面手动下载安装包；新修复不会自动改变旧版下载逻辑。

## 验证结果

- 更新插件 181 项测试及 TypeScript 类型检查通过，覆盖二进制下载、校验与失败返回行为。
- 平台安装包由 GitHub Actions 构建并检查；发布不代表所有网络环境均已真机验收。

## 已知限制

- 代理、网络权限及远程下载服务故障仍可能导致下载失败。
- macOS 和 Windows 的真实覆盖安装及应用内更新流程仍需预发布验证。
- 循环护栏保留 0.5.9 的限制，不保证终止所有循环。

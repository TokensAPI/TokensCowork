# TokensCowork v0.7.0

将 Desktop 内核升级到上游 v2.0.18，并跟随其固定的 DSH 0.2.1-rc.2：上游新能力全部继承，产品只处理与自营插件市场、品牌和发布流程的冲突；随包分发 Python/Node 解释器运行时与 Office 技能。

## 本次更新

### ✨ 新增功能

- 来自上游 DSH 0.2.1：内置 DeepSeek-V4.1-Flash 模型目录项；自定义模型可编辑推理档位；模型标签按供应商提供；输入框与设置页的模型菜单保持在视口内。
- 来自上游 Desktop 2.0.18：随包分发 Python 3.12 / Node 24 解释器运行时并挂载 Office 技能（文档、表格、演示文稿的处理不再依赖本机环境）；官方编辑右键菜单；开发者诊断扩展到稳定版；首次引导可选择插件市场。
- 插件的安装、卸载、启用、停用改由官方插件管理器即时应用，**不再需要重启应用**；"已安装"页显示版本号并提供启用/停用开关。

### 🐛 问题修复

- 市场在慢网络下安装插件：下载预算放宽到 10 分钟，服务端改为边拉边回并缓存已校验的安装包，超时时明确提示"下载安装包超时，请检查网络后重试"（v0.6.1 之后上线的服务端改动在此一并说明）。
- 市场的一键更新沿用官方语义"先卸载当前版本再安装新版"，确认弹窗会说明配置保留；更新失败时提示从市场重新安装。
- 产品自身的拒绝原因（配置冲突、API Key 格式错误）不再被包装成通用的"包管理器失败"。
- 修复更新检查在授权目标未就绪时静默回退到上一次缓存目标的问题。

### ⚠️ 其他变更

- Desktop 从 v2.0.17 升级到上游稳定标签 v2.0.18，固定提交 `6a63b9730b82cf4e858b9a11ac9783da9a5a0c3a`；DSH 从 0.2.0-rc.2 升级到 0.2.1-rc.2，固定提交 `687f282e8625c6b8d11ff58211a90524be2e4317`。
- 上游把插件安装全部交给官方插件管理器，市场不再自行运行包管理器；私有 Registry 鉴权与下载预算改为安装期间一次性的临时配置，用完即删。
- 上游停发 `@deepseek-ai/dsh-invariants`，产品保留其最后发布版供"TokensCowork 更新"插件使用，待插件去掉该依赖后移除。
- 侧栏"插件"页的"添加插件"入口（DSH 0.2.1 起为下拉组）仍由产品去掉，插件统一通过插件市场安装。
- 产品版本使用 v0.7.0，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.6.0 相同，仍不支持回退到 0.5.x。

- 内置六插件与四个市场插件（connect 2.9.5、plugin-check 0.4.5、progressive-tools 0.2.6、meeting-transcription 0.2.13）的兼容声明用宿主评估器对 0.2.1-rc.2 实测全部通过。

## 已知限制

- 通过 TokensAPI 使用 gpt 系列模型时，上游渠道目前只接受 Codex 客户端，发送消息会失败（界面显示为 "API key is invalid"）；待 TokensAPI 侧调整后恢复，其他模型不受影响。
- 市场一键更新"先卸载再安装"的即时生效与配置保留尚未在真实设备上验证；更新中途失败时插件会被卸载，需从市场重新安装。
- Discover 首页的视觉验收尚未完成。
- 升级会迁移设置与会话格式，降级回 0.5.x 会丢失这部分设置和会话的显示。

## What's New

### ✨ New Features

- From upstream DSH 0.2.1: a bundled DeepSeek-V4.1-Flash catalog entry; editable reasoning levels for custom models; provider-aware model labels; model menus stay inside the viewport.
- From upstream Desktop 2.0.18: a bundled Python 3.12 / Node 24 interpreter runtime with Office skills mounted (document, spreadsheet and presentation handling no longer depends on the host machine); the official editing context menu; developer diagnostics on Stable; plugin-market choice during onboarding.
- Installing, uninstalling, enabling and disabling plugins is now applied immediately by the official plugin manager — **no restart required**; the Installed view shows versions and enable/disable switches.

### 🐛 Bug Fixes

- Installing market plugins on slow networks: the download budget is raised to 10 minutes, the server streams tarballs and caches verified archives, and a timeout is reported as "download timed out, check your network and retry" (server-side changes shipped after v0.6.1 are described here as well).
- One-click updates follow the official semantics "uninstall the current version, then install the new one"; the confirmation explains that configuration is kept, and a failed update tells you to reinstall from the market.
- Product refusals (configuration conflicts, malformed API keys) are no longer wrapped as a generic package-manager failure.
- Fixed update checks silently falling back to the last cached target before the authorized target was ready.

### ⚠️ Other Changes

- Upgrade Desktop v2.0.17 to the stable upstream tag v2.0.18 (`6a63b9730b82cf4e858b9a11ac9783da9a5a0c3a`) and DSH 0.2.0-rc.2 to 0.2.1-rc.2 (`687f282e8625c6b8d11ff58211a90524be2e4317`).
- Upstream now routes all plugin installs through the official plugin manager; the market no longer runs the package manager itself, and private-registry credentials plus the download budget are written as a per-operation temporary configuration that is removed afterwards.
- Upstream discontinued `@deepseek-ai/dsh-invariants`; the product keeps its last published version for the "TokensCowork Updates" plugin until that dependency is dropped.
- The "Add plugin" entry on the sidebar Plugins page (a dropdown group since DSH 0.2.1) is still removed by the product; plugins are installed through the plugin market.
- The product version is v0.7.0 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.6.0, and downgrading to 0.5.x is still unsupported.

## Verification

Overlay doctor: 69 overlays with none broken and none obsolete; market overlays were re-anchored on 2.0.18 and four product rewrites now provided upstream were retired. Build-code regression, market server and overlay tests passed; the staged Market suite passed 336 cases with 9 product-policy skips. Compatibility declarations of the six bundled and four market plugins were evaluated against 0.2.1-rc.2 with the host's own evaluator and all passed. The full product gate (`build.mjs check`) and the three-platform rehearsal build are recorded as of publication; installation, account sign-in and model conversation checks of the v0.7.0 installers on real devices have not been performed yet.

## Known Limitations

GPT models via TokensAPI currently fail to send because the upstream channel only accepts the Codex client (shown as "API key is invalid"); other models are unaffected. The immediate activation and configuration retention of the market's uninstall-then-install update have not been verified on a real device; a failed update leaves the plugin uninstalled until reinstalled from the market. Visual acceptance of the Discover home is pending. Upgrading migrates settings and session formats; downgrading to 0.5.x loses the display of those settings and sessions.

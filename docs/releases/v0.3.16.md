# TokensCowork v0.3.16

本预发布版本把助手身份从编程助手升级为全能助手，修复被删除的官方插件源无法恢复的问题，并为插件市场目录源引入动态管理与自动部署。

## 本次更新

### 新增

- 插件市场目录源升级为动态服务：新增 npm 自动同步与管理面板（roster 驱动的 Cloudflare Worker），目录源在仓库推送后自动部署，无需手动发布。

### 修复

- 官方插件源自愈：旧版本允许删除官方源且空状态会持久保留，重装也不恢复。现产品启动时检查并自动补回必需来源（只写一次），市场不再会进入不可恢复的空源状态。

### 优化

- 助手身份全面切换：系统提示词的源码检出说明、Web GUI 说明与全部 agent 预设 persona 均改用 TokensCowork 品牌，身份从"编程助手"改为覆盖编码、研究、写作与日常任务的全能助手；每处替换带构建期守护。

## 安装说明

> **旧版本用户请注意**：v0.3.13 及以前版本（含 TokensHarness 0.3.9）因仓库迁移无法自动检测更新，请手动下载本版本安装；安装后自动更新恢复正常。

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 从 TokensHarness 旧版本升级会自动卸载旧版本，用户数据目录自动迁移到 TokensCowork 并保留。
3. 如果旧文件仍被占用，先完全退出应用和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入"应用程序"。
3. 未正式公证的构建首次启动时，需要右键应用并选择"打开"。

## 验证重点

1. 会话系统提示词中无 "DeepSeek Harness" 与 "coding agent" 残留，身份为 TokensCowork 全能助手。
2. 曾删除官方插件源的旧配置升级后，打开市场即可看到官方源自动恢复。
3. 插件市场目录随仓库推送自动更新，管理面板可用。
4. 从 v0.3.15 覆盖升级正常，用户数据保留。

## 验证结果

- 助手身份替换经干净装配全链验证：三处编译产物与三个预设 persona 均带出现次数守护落盘。
- 官方源自愈带 source-store 回归测试与 lifecycle 异步时序适配；市场测试套件全量通过（267 项通过、8 项按产品策略跳过）。
- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- 受限沙箱基础设施熔断为会话级：触发后需重启会话恢复对应受限模式。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

# TokensCowork v0.5.11

修复循环护栏提醒缺少消息身份导致批量调用中断及后续日志导出失败的问题，同时更新模型目录同步和搜索诊断逻辑。

## 本次更新

- 循环护栏达到阈值后持续返回纠正反馈，不再仅处理跨阈值的一次调用。
- 每条提醒和阻断通知包含唯一 ID 与用户角色，符合 DSH 持久化消息契约。
- 模型管理器更新至 0.2.22，修复启动模型目录同步。
- WebSearch 更新空结果诊断重试反馈；同步插件测试入口。
- 本地开发启动自动同步产品派生清单，允许未暂存的产品指针，CI 保持严格校验。

完全退出后覆盖安装。无需清理用户配置或会话；旧版本更新下载失败时请手动下载安装包。

## 验证结果

- 护栏 14 项测试通过；当前 DSH 存储校验、批量通知唯一性、用户继续后的计数重置和 ZIP 往返验证通过。
- 更新插件 40/40、WebSearch 53/53 功能用例通过。
- 模型管理器 87 项清单：36 项完整通过，41 项自动化部分通过，10 项人工场景未运行，不计为全量通过。
- 外层构建及开发启动、发布相关回归通过。真实桌面界面及跨平台安装仍由预发布验收确认。

## 已知限制

- 修复防止新异常消息产生，不自动修复旧版已经写入缺失 ID 消息的历史会话。
- 护栏仍在工具执行后提供反馈，不撤销已执行操作，也不保证所有循环都结束；近似匹配仍可能误判。
- 自动化契约测试不等同于真实界面导出或所有模型、网络环境验收。
- 模型管理器未运行的人工场景：INS-005、PLAT-004、PLAT-005、E2E-001、E2E-002、E2E-003、E2E-004、E2E-005、E2E-007、E2E-008；其他部分自动化场景仍有人工验证缺口。

# TokensCowork v0.5.13

内置 TokensAPI 账户插件，支持通过系统浏览器登录账户，并为模型插件配置账户所属的 API Key。

## 本次更新

- 默认启用 tokens-login 0.1.5，固定源码提交 a0019053b223951a622aba11544e149f0dc73341。
- 登录后按账户归属复用或配置 API Key，避免继续使用其他账户遗留的 Key。
- 同步内置组件清单及产品依赖锁文件；沿用 v0.5.12 的外部浏览器桥。

## 下载说明

以 pre-release 发布，三个平台构建成功后提供附件。

- Windows amd64：`TokensCowork-0.5.13-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.13-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.13-macos-amd64-installer.dmg`

## 安装说明

完全退出应用后覆盖安装，无需删除用户配置或会话。

## 验证结果

- 外层构建回归 70 项通过。
- 登录插件在固定提交的 LF 临时副本中 50 项测试通过，包含账户 Key 归属、浏览器回调及包内容校验。
- Windows CRLF 工作区存在一项发布工作流文本断言失败；原始 LF 源码复测通过，未修改插件源代码。

## 已知限制

- 本次未重新执行真实站点登录和跨平台安装验收；安装包以 GitHub Actions 构建结果为准。

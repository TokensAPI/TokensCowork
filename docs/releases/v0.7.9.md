## 本次更新

### 🎨 体验优化

- 插件市场「发现」页的卡片右上角显示安装状态：可安装的插件是绿色带圆圈的「＋」，已安装的是灰色的「✓」，内置插件不显示。已安装的卡片底色略深一档，不再整块变灰。点图标与点卡片一样打开原来的插件弹窗，安装、卸载与确认步骤不变。

### ⚠️ 其他变更

- 插件市场服务的会话日志后台改为「对话」与「原始 JSON」两个视图：对话按轮次只露出用户的话和模型的最终回答，中间过程折叠；原始 JSON 可下载。这部分在服务端，已于本版本之前部署，不依赖安装包。
- 内置插件与 v0.7.8 相同。
- 产品版本使用 v0.7.9，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🎨 Improvements

- Cards on the plugin market's Discover page now show their install state in the top-right corner: a green circled "+" for plugins you can install and a grey "✓" for installed ones; built-in plugins show neither. Installed cards get a slightly deeper background instead of turning grey all over. Clicking the mark does the same as clicking the card and opens the plugin's existing dialog, so installing, uninstalling and the confirmation steps are unchanged.

### ⚠️ Other Changes

- The session log console in the plugin market service now has a Conversation view and a Raw JSON view: the conversation shows each turn's user message and final model reply with the steps in between folded away, and the raw JSON can be downloaded. This lives on the server, was deployed before this release and does not depend on the installer.
- Built-in plugins are unchanged from v0.7.8.
- The product version is v0.7.9 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

Plugin market cards: the market overlay cases, the overlay doctor, and the type checks and client suite on staging all pass; renders in the dark and light themes were checked, and the user looked at the result in the product started with the test script. The CI Windows quality gate passed in full (assembly, dependency install, runtime and compaction smoke tests, plugin compilation, type checks, branding checks, plugin real-host contracts and built-in plugin regression), build run 41575102578. Installation and interface acceptance of the v0.7.9 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.8: GPT models via TokensAPI currently fail to send because the upstream channel only accepts the Codex client; downgrading to 0.5.x loses the display of migrated settings and sessions; a failed route save after a model pick reverts the button and logs the reason without a toast; the first open of the market Discover still takes about 1–2 seconds; English release notes in the dialog show highlights but no summary; a very long highlight shows only the whole sentences that fit; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request.

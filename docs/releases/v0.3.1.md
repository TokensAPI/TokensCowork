# TokensHarness v0.3.1

本版本在 v0.3.0 纯净正式版的稳定 Desktop 与 DSH 基线上，重新内置此前验证过的 TokensHarness 产品插件，作为包含完整产品能力的正式版本发布。

## 本次更新

### 产品插件

- 默认启用 TokensHarness 更新插件 `@tokens/dsh-version-updates` 0.1.0，用于检查并下载 TokensHarness GitHub Release 更新。
- 默认启用飞书连接插件 `@tokens/dsh-feishu-connect` 0.1.4，提供飞书/Lark 应用、OAuth、文档与消息能力。
- 默认启用 TokensAPI 模型管理插件 `@tokens/dsh-model-manager` 0.2.1，包含受管会话路由稳定性修复。
- 不包含尚未完成产品验证的 Web Search、Browser Use、TokensAPI UI 或其他候选插件。

### 稳定基线

- 保持最新 Verified DSH Desktop 提交 `d457d790295e727bbb1fc20e398da602f521fd64`。
- 保持该 Desktop 官方锁定的 DeepSeek Harness 提交 `141eb6fef83422698aef7a981029e843e8161534`（`0.1.0-rc.8`）。
- 不混用 Desktop 尚未验证的 DSH `0.1.1-rc.1` 或未签名 Desktop HEAD。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.3.1-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.3.1-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.3.1-macos-amd64-installer.dmg` |

安装包及 SHA-256 校验文件仅从本仓库 `v0.3.1` GitHub Release 下载。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库 Release。
3. 首次启动后按提示配置 TokensAPI 模型；需要飞书能力时再完成飞书授权。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 产品布局检查验证 Desktop、嵌套 DSH 与三个产品插件的固定提交。
- 产品装配必须显示 `3 default plugin(s)`，且插件清单只包含版本更新、飞书连接和 TokensAPI 模型管理。
- Windows amd64、macOS arm64 与 macOS amd64 安装包由 GitHub Actions 分平台构建并校验 SHA-256。
- Desktop 编译、类型检查、运行时闭包、许可证门禁、品牌与插件生产依赖由正式发布工作流验证。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 尚未验证的候选插件不会随本版本安装。

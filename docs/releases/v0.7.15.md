## 本次更新

### 🔧 改进

- 插件市场打开时只检查一次插件更新，「发现」、插件详情和「已安装」都用这次的结果，不再每点开一个插件或切一次页面就重新检查；手动「检查更新」、安装/卸载/更新插件之后，以及关掉再打开市场时才会重新检查。

### ⚠️ 其他变更

- 设置 → 通用设置里不再显示「在使用 TokensAPI 时上传 Session Log」开关：组织成员默认上传，非组织用户不上传（会话日志插件 0.1.4）。
- 产品版本使用 v0.7.15，发布时设置 GitHub Pre-release 标记；升级与降级说明与 v0.7.0 相同，仍不支持回退到 0.5.x。

## What's New

### 🔧 Improvements

- The plugin market checks for plugin updates once when it opens; Discover, plugin details and Installed reuse that result instead of re-checking on every plugin opened or view switched. It checks again only on a manual "Check for updates", after a plugin is installed, uninstalled or updated, and when the market is closed and reopened.

### ⚠️ Other Changes

- Settings → General no longer shows the "Upload Session Log when using TokensAPI" toggle: organization members upload by default and other accounts do not (session log plugin 0.1.4).
- The product version is v0.7.15 and is marked as a GitHub Pre-release; upgrade and downgrade notes are unchanged from v0.7.0, and downgrading to 0.5.x is still unsupported.

## Verification

Session log 0.1.4: plugin tests have no failures and 9 host contract tests pass; the overlay registry check found no drift and build-code regression passed 229 cases. Plugin market update check: count-based tests pass (1 check on open; 0 for details, Installed and returning to Discover; +1 each for a manual check, after an install and on reopen), along with 60 market overlay cases, the overlay assembly check, TypeScript checks and 361 frontend tests. Installation and interface acceptance of the v0.7.15 installers on real devices have not been performed yet.

## Known Limitations

Same as v0.7.14: the Store edition is not listed yet and its built-in TokensCowork updater still checks GitHub releases like the EXE edition; downgrading to 0.5.x loses the display of migrated settings and sessions; session logs are uploaded before each model request, so a turn's last reply is uploaded only with that session's next request.

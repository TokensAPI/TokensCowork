# TokensHarness v0.2.4

本版本默认内置 TokensAPI 模型管理插件，首次进入 Desktop 前验证 API Key，并让文本视觉桥接、原生多模态与普通直连模型保持一致的选择和会话行为。

## 本次更新

### TokensAPI 模型管理

- 默认内置 `@tokens/dsh-model-manager` 0.1.0，固定到提交 `239636e780b2527804b7da6c00ea38838709f8a9`。
- 首次进入 Desktop 前要求输入并验证 TokensAPI API Key；验证成功后才开放聊天和识图功能。
- 支持从 TokensAPI 模型列表选择主模型，并在保存 API Key 或模型选择后同步当前会话与后续新会话。
- 对 DeepSeek、GLM 文本模型使用“主文本模型 + 视觉模型”的 ModLens 组合，并默认选中组合 provider。
- 对明确声明图片输入能力的原生多模态模型直接使用主模型，不再显示额外视觉模型配置。
- 对能力未知或不支持视觉桥接的模型使用普通直连模式，不再误标为原生多模态。
- 会话模型目录只发布当前选中的主模型，避免其他 TokensAPI 模型或不适用的视觉包装项混入选择器。
- API Key 默认隐藏，可按需显示或复制，状态接口不会返回 Key 或其指纹。

正式安装包仅从本仓库的 `v0.2.4` GitHub Release 下载，并使用同一 Release 中的 `TokensHarness-0.2.4-SHA256SUMS.txt` 校验。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库正式 Release。
3. 启动 TokensHarness，根据全屏提示输入 TokensAPI API Key 并完成验证。
4. 进入“设置 → 模型”选择主模型；文本模型可同时选择视觉模型，原生多模态或直连模型会隐藏该选择项。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。
4. 启动后输入并验证 TokensAPI API Key，再按需选择模型。

## 验证结果

- 模型管理与 Desktop 客户端相关回归共 142 条，全部通过。
- 插件 lint、TypeScript 类型检查和独立生产构建全部通过。
- 插件生产依赖仅包含 `commander` 13.1.0 与 `undici` 8.10.0，完整生产依赖许可证均为 MIT。
- 产品版本元数据、发布说明、插件固定提交和依赖锁通过发布前检查；正式安装包由 GitHub Actions 在干净环境构建和校验。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 模型原生图片能力依据 DSH 提供的模型元数据判断；能力未明确声明时按直连模式处理，不会自动执行消耗额度的图片请求进行探测。
- 全仓 Windows 安全测试中依赖创建符号链接的 6 条用例在未授予符号链接权限的系统上会返回 `EPERM`；与本次模型管理逻辑无关。

# TokensHarness v0.3.8

本预发布版本修复 Windows 覆盖升级可能留下半新半旧安装目录的问题，并加入统一的飞书连接中心，重点验证从上一稳定版自动升级到新版本的完整流程。

## 本次更新

### Windows 覆盖升级

- 新安装器在调用旧卸载器后检查实际安装目录，不再只相信可能失真的退出码。
- 旧文件仍被应用、后台进程或安全软件占用时，安装器会明确停止并保留完整旧版本，不再继续解压造成混合安装。
- 本版本生成的卸载器会在更新删除失败时返回非零状态，使后续安装器能够重试并正确提示用户关闭应用。
- 修复本机卸载辅助脚本对 electron-builder GUID 注册表项和空 `InstallLocation` 的识别，可从真实卸载命令推导安装目录。

### 飞书连接中心

- 内置 `tokens-feishu-connect` 0.2.1 和 `tokens-connect-ui` 0.1.0，提供统一的桌面连接配置入口。
- 产品构建器执行插件声明的可复现客户端构建，并在打包前裁剪源码构建工具和非运行时内容。
- 保留既有联网搜索、TokensAPI 模型、本地文件引用和版本更新插件。

### 构建验证

- Windows Action 自动下载上一稳定版，先完成旧版安装，再模拟文件被占用的升级失败。
- 校验失败升级不会改写旧主程序；解除占用后，同一个新安装器必须自动卸载旧版并升级成功。
- 覆盖升级测试复用本次已经生成的 Windows 安装器，不增加第二次 Desktop 完整构建。

本版本默认作为 GitHub Pre-release 发布；验证完成后再单独确认是否进入稳定更新通道。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 正常升级会自动卸载旧版本并保留 `%APPDATA%\TokensHarness` 用户数据。
3. 如果旧文件仍被占用，先完全退出 TokensHarness 和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证重点

1. 从上一稳定版直接运行 `0.3.8` 安装器，能够自动保留数据并完成覆盖升级。
2. 人为占用旧安装文件时，安装器必须失败且旧主程序版本保持不变。
3. 解除文件占用并重试后，无需手动删除安装目录即可升级成功。
4. 飞书连接中心能够打开、保存配置并调用飞书连接 Host RPC。
5. 联网搜索、TokensAPI 模型、本地文件引用和版本更新入口保持正常。

## 验证结果

- 卸载命令解析、注册表记录规范化、残留目录判断和 NSIS 升级保护均有自动化测试。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。
- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

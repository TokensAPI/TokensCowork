# TokensHarness v0.2.3

本版本默认内置飞书连接插件，并修复飞书授权确认页跳转到官方开放平台域名后无法继续注册的问题。

## 本次更新

### 飞书连接

- 默认内置 `@tokens/dsh-feishu-connect` 0.1.4，固定到提交 `3c6f739d33e6015f667b267b1b52dcf452fe14d1`。
- 支持飞书和 Lark 当前使用的官方确认页域名 `open.feishu.cn` 与 `open.larksuite.com`，同时兼容原有 accounts 域名。
- 继续拒绝非 HTTPS 地址和无关域名，避免授权流程接受不可信的确认链接。
- 桌面产品打包时将插件的 TypeScript 入口编译为 `dist/index.js`，确保默认安装后可直接加载运行。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.2.3-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.2.3-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.2.3-macos-amd64-installer.dmg` |

正式安装包仅从本仓库的 `v0.2.3` GitHub Release 下载，并使用同一 Release 中的 `TokensHarness-0.2.3-SHA256SUMS.txt` 校验。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库正式 Release。
3. 安装完成后启动 TokensHarness，飞书连接插件会随桌面产品默认启用。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 飞书连接插件独立测试共 109 条，全部通过。
- 实际飞书注册接口返回的 `open.feishu.cn` 确认页已通过可信地址校验。
- 产品依赖锁已包含 `@tokens/dsh-feishu-connect`，桌面暂存流程可编译并装配两个默认插件。
- 版本元数据、插件固定提交和默认启用配置通过检查。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 飞书连接仍需用户完成飞书或 Lark 官方授权流程，并受对应平台接口与账号权限限制。

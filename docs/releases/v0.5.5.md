# TokensCowork v0.5.5

改进 TokensAPI 模型协议分类、切换验证和 Claude／GPT 兼容性，让新增及升级型号无需逐个写死协议规则。

## 本次更新

- GPT、Codex 与 Claude 按模型家族自动选择原生协议，支持带供应商命名空间及后续新增版本。
- DeepSeek、Qwen、Gemma、GLM 和未知家族默认使用 Chat Completions，同时提供模型目录声明或兼容回退中的其他候选协议。
- 切换非默认协议前执行完整流式验证；结构、路由和终止事件错误会阻止保存，限流、服务端及网络故障保留为可重试状态且不覆盖原配置。
- Claude Messages 经本机回环兼容代理使用正确路径和请求身份；GPT／Codex Responses 不再发送网关不支持的输出上限字段。
- 过滤语音识别等非对话模型，并合入 GPT 6 显示能力与最新版内置网页搜索插件固定提交。

## 验证结果

- 模型管理及 DSH 回归 348 项通过，5 项按环境跳过；类型检查、Lint 和插件构建通过。
- 对 27 个可见模型执行 81 条真实协议请求；家族规则禁止的 28 条全部失败，48 条候选成功，两个 Qwen Responses 异常流与 Kimi 临时 503 均被保存前验证正确拦截。
- 全量插件测试 908 项通过、61 项跳过；5 项并行 Windows 超时用例单线程复跑 94 项全部通过、1 项跳过。
- 安装包及跨平台签名、升级和打包验证以 CI 结果为准。

## 已知限制

- Kimi K3 当前由服务端返回 503，插件将其视为临时服务故障，不会永久禁用协议。
- 普通模型的其他协议通过短流式请求验证后方可保存；工具调用、图片及超长上下文仍取决于对应模型和网关能力。

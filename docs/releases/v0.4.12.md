# TokensCowork v0.4.12

修复自建来源插件在“发现”中可见、但“可安装”列表为空的问题，并完善插件市场的新旧来源兼容与仓库下载授权。

## 本次更新

- 安装候选筛选同时支持 npm 和 tokenscowork，自建来源不再被错误过滤。
- 新版通过 Market 从自建仓库读取版本并下载；旧客户端继续使用仍保留在公开 npm 的版本。
- 自有插件仓库直连仅向内部发布者及市场服务开放，最终用户的公开或受限下载由市场授权决定。
- 上游 Desktop、Harness 及内置插件固定提交不变。

## 下载说明

构建成功后，从此 Release 下载 Windows amd64、macOS arm64 或 amd64 对应安装包，并核对 SHA256 文件。此 Release 标记为预发布，供升级验证。

## 安装说明

- Windows：退出应用后运行安装包，覆盖安装保留用户数据。
- macOS：将应用拖入“应用程序”并替换旧版。
- 升级后打开插件市场，在“可安装”页重新检查；受限插件需要已授权的 API Key。

## 验证结果

- 本地市场客户端全量测试 269 项通过、9 项跳过，类型检查通过。
- 新增真实安装候选列表测试，覆盖公开 npm 和自建来源；构建 overlay 回归测试通过。
- 市场与仓库相关 147 项测试通过；线上已验证公开下载成功、受限入口拒绝未授权请求、仓库拒绝匿名直连。
- 本地市场模块构建通过；各平台完整构建、生产依赖许可证门禁和安装器检查由 Build Desktop 执行。
- 尚未完成此版本安装包在真实应用中的安装、启用、更新、卸载全流程人工验收。

## 已知限制

- 浏览器操作、媒体生成、插件体检、渐进式工具已撤下公开 npm。不支持自建来源的旧客户端无法再通过原路径安装它们。
- 已下载的文件及第三方缓存无法收回；内部仓库账号不能分发给最终用户。
- Windows 安装器未签名，可能出现 SmartScreen 提示；macOS 签名和公证状态以构建产物为准。
- 不提供 Windows ARM64、32 位或 Linux 安装包。

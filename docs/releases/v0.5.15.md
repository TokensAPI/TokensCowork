## 本次更新

### 🐛 问题修复

- 账户会话被服务拒绝时明确提示重新登录，保留模型 API Key；修复密钥列表加载失败后一直等待、无法重试的问题，避免将网络或账户业务错误误判为会话过期。
- 更新下载处理短写、截断、取消和不安全文件名，清理未完成下载并保留已有安装包；托盘与原生更新弹窗跟随宿主中英文语言。
- 联网搜索取消后及时结束竞速，不再启动后续引擎；隔离缓存结果对象，设置变化后清空缓存并阻止旧请求回填。校验时间过滤参数，保留引擎原始内容与回退说明。

### 🎨 体验优化

- 搜索引擎切换使用宿主命令界面与语言服务，明确显示加载、保存或重载失败；更新模型获得的搜索说明，使其准确描述引擎竞速与失败边界。
- 下载页仅显示所选版本的完整改动，移除重复升级摘要；修复 GitHub 发布说明的中英文跳转链接。

### ⚠️ 其他变更

- 账户插件升级到 0.1.7，更新插件升级到 0.1.1；WebSearch 保持 0.2.0 版本号并固定到新的修复提交。其他组件沿用 v0.5.14 的固定版本。
- 本说明展示相对 v0.5.14 的变化。预发布和稳定版共用固定模板，转稳定版时再合并上一稳定版以来的内容。

## What's New

Fix expired account-session recovery, interrupted update downloads and bilingual dialogs, and improve search cancellation, cache isolation and engine switching.

### 🐛 Bug Fixes

- Prompt users to sign in again when an account session is rejected while preserving the model API key. Restore retry controls after key-list failures, and avoid treating network or account business errors as expired sessions.
- Handle short writes, truncated downloads, cancellation and unsafe asset names. Clean up incomplete downloads while preserving existing installers; localize tray items and native update dialogs using the host locale.
- Stop search races promptly on cancellation without starting further engines. Isolate cached result objects, clear the cache when settings change, and prevent stale requests from repopulating it. Validate time filters and preserve original engine content alongside fallback notices.

### 🎨 Improvements

- Use the host command UI and locale service for engine selection, reporting load, save and reload failures. Give models accurate guidance about engine racing and failure boundaries.
- Show only the selected release’s full changes on the download page, remove the duplicate upgrade summary, and fix bilingual links in GitHub release notes.

### ⚠️ Other Changes

- Update the account plugin to 0.1.7 and the updater to 0.1.1. WebSearch retains version 0.2.0 with a new pinned fix commit; other components retain their v0.5.14 pins.
- These notes describe changes since v0.5.14. Candidates and stable releases use the same template; promotion consolidates changes since the preceding stable release.

| TokensAPI Account | 0.1.7 | Expired sessions and key-list retries |

## Installation

### Windows Installation

1. Download the Windows amd64 installer and fully quit TokensCowork.
2. Run the installer and follow its instructions.
3. Signing status and system prompts: The Windows installer is not Authenticode-signed and may trigger SmartScreen. Verify that it came from this repository’s release.

### macOS Installation

1. Check your processor in About This Mac and select the Apple Silicon or Intel installer.
2. Fully quit TokensCowork, open the DMG, and drag the application into Applications.
3. First launch, signing and notarization: Refer to the build records for signing and notarization status. If macOS blocks launch, verify the download source before using the system’s Open action.

### Upgrading from an Earlier Version

- Data and configuration retention: Installing over the existing application preserves configuration and sessions; cross-platform data retention has not been manually verified.
- Required migration or compatibility steps: No manual configuration migration is required for this update.
- Plugin updates, restarts or reauthorization: Fully quit the application before installation, then restart to load updated bundled components. Sign in again if the account session expires; temporary API-key sign-in retains its existing restart behavior.

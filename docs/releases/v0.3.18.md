# TokensCowork v0.3.18

本预发布版本打通插件市场的一键安装与更新，并让 TokensAPI 模型选择按会话独立保留。

## 本次更新

### 新增

- 插件市场支持原地更新：已由市场安装的插件出现更高版本时，直接显示“更新到 x.x.x”，完成后显示“插件更新完成”。
- 历史上按提示手动安装的产品插件，可在 registry、repository、integrity 与 bundle 全部验证通过后由市场接管并更新。

### 修复

- 修复预编译产品 npm 包因保留 publish-time `prepare` 而被误判为需要手动安装的问题；仅产品清单中的受管包获得豁免，真正的安装生命周期脚本仍被拒绝。
- 修复启动或切换会话时中央主模型覆盖会话已有选择的问题；每个会话保留自己的模型，未选择模型的新会话仍使用主模型作为默认。

### 优化

- TokensAPI 会话选择器展示当前协议下的完整可用模型目录，隐藏重复实现线路，并将主模型排在首位。
- Tokens Cowork UI 固定到 0.2.16，模型管理插件固定到 0.2.14 的最新验证提交。

本版本默认作为 GitHub Pre-release 发布，验证完成后可在 Release 页面转为稳定版本。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 如果旧文件仍被占用，请先完全退出应用和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- Market 完整测试通过：19 个测试文件，271 项通过，8 项按既有产品策略跳过；TypeScript、装配、导出与加载检查通过。
- 使用真实 npm registry 元数据验证 `@tokensapi/dsh-progressive-tools@0.1.0` 的受管安装路径通过。
- 模型插件 lint、TypeScript 与构建通过；模型管理与会话目录相关测试 206 项全部通过。
- 父仓库产品布局、Desktop 完整检查和 Windows 安装包由本次发布流程验证与生成。

## 已知限制

- 市场只接管产品清单中的 npm 插件，且只允许升级到严格更高的稳定三段版本；验证失败的历史安装仍保持手动管理。
- 会话选择器只展示与当前主模型协议兼容的模型；切换到其他协议的模型需要先在模型管理页将其设为主模型。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

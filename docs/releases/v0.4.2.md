# TokensCowork v0.4.2

本次为紧急修复版本：修复 v0.4.0 / v0.4.1 安装包在真机上无法创建会话、无法选择项目、续聊报错的问题。强烈建议所有 v0.4.x 用户升级。

## 本次更新

### 关键修复

- 修复安装版预设无法挂载（`agent-presets: preset "standard" failed to mount: 23 rows name plugins that cannot be resolved`）：v0.4.x 打包把 DSH 运行时收进 app.asar，模块导入经注册的解析钩子正常工作，但预设健康检查以裸文件系统遍历 `node_modules` 判定插件可用性——asar 内的运行时包全部被误判为缺失，导致新会话、项目选择与续聊全部失效。产品在打包前为健康检查补上 asar 感知：文件遍历失败时改问模块解析器（只解析、不执行，语义不变），并新增打包门禁：补丁未进入安装包则构建失败。

### 说明

- 用户数据与会话记录不受影响：该缺陷只影响运行时解析，不读写用户数据。升级安装 v0.4.2 后即可恢复正常使用。
- 已安装 v0.4.0/v0.4.1 的用户直接覆盖安装本版本即可，无需卸载。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需要右键应用并选择“打开”。

## 验证结果

- 真机复现并定位：v0.4.1 安装版 asar 内 232 个 `@deepseek-ai` 运行时包齐全，但预设健康检查经真实文件系统不可见；补充旁路运行时文件后立即恢复，确认解析可见性即根因。
- 补丁后的 agent-presets 模块导入验证通过（22 个导出完整）；解析回退在已安装环境命中、在空环境正确落空。
- 新增 verify-package 门禁：断言安装包 asar 内的预设健康检查携带 asar 感知补丁，缺失则构建失败，防止同类回归再次发布。
- 产品布局、版本钉定、市场名册一致性与快照闸门全部通过。
- 完整的桌面与市场测试套件、运行时闭包与许可证门禁由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- 已在 v0.4.0/v0.4.1 下启动过的现有安装此前被记录为“市场关闭”，且无法与用户显式关闭区分，升级后不会自动翻转；可在设置中手动启用插件市场。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

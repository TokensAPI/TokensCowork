# TokensHarness v0.1.9

本版本撤回尚未完成产品验证的 TokensAPI UI 插件，仅保留已经确认的版本更新、模型管理和飞书连接插件。

## 本次更新

### 修复

- 停止在正式安装包中默认装配 `dsh-tokensapi-ui` 0.1.0。
- 保留 TokensAPI UI 源码固定记录供后续独立验证，但不会下载其发布制品、写入产品 workspace、注册 Cordis 插件或进入安装包。
- 保持飞书连接插件 0.1.3 的运行时依赖解析修复。

### 构建

- 默认产品插件恢复为三个：版本更新、模型管理和飞书连接。
- Windows amd64、macOS arm64 与 macOS amd64 使用同一固定依赖图构建。
- 发布工作流继续校验固定提交、完整 profile 启动、运行时闭包、许可证和产品品牌。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.9-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.9-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.9-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 未签名版本首次启动时需要右键选择“打开”。

## 验证结果

- 产品装配摘要必须只显示三个默认插件。
- staging workspace、桌面宿主依赖和 Cordis patch 中不得包含 `dsh-tokensapi-ui`。
- 三个平台成功后统一生成安装包 SHA-256 校验文件。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。
- 飞书连接功能需要用户自行提供有效的飞书应用配置。
- 模型路由请求 TokensAPI 需要有效的 `TOKENSAPI_API_KEY` 凭据。

# TokensCowork v0.3.15

本预发布版本完成系统提示词品牌切换，加固插件市场产品源保护，并升级 Tokens Cowork UI。

## 本次更新

### 新增

- 插件市场产品源保护：固定官方源的添加、删除入口与合作说明全部隐藏，Host 侧同时拒绝删除该来源，避免误操作导致市场不可恢复；市场中英文副标题同步切换为 Tokens Cowork。

### 修复

- 系统提示词品牌切换：关闭上游 DeepSeek Harness 身份行，改用当前产品名称生成简洁的 TokensCowork persona，运行时不再暴露旧品牌；工具说明与运行时上下文保持上游原样。

### 优化

- Tokens Cowork UI 升级到 0.2.11：浮动选择表面主题泛化等界面修复。
- 构建系统整理：Windows 装配资产按用途归类（ACL 启动链 / 安装器），补丁层品牌覆盖收敛进主题模块，新增装配目录说明与覆盖编写约定。

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensCowork-0.3.15-windows-amd64-installer.exe` |

本版本默认作为 GitHub Pre-release 发布；验证完成后再单独确认是否进入稳定更新通道。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 从 TokensHarness 旧版本升级会自动卸载旧版本，用户数据目录自动迁移到 TokensCowork 并保留。
3. 如果旧文件仍被占用，先完全退出应用和托盘进程，再重新运行安装器。
4. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入"应用程序"。
3. 未正式公证的构建首次启动时，需要右键应用并选择"打开"。

## 验证重点

1. 会话中导出或查看系统提示词，身份行为 TokensCowork persona，无 DeepSeek Harness 品牌残留。
2. 插件市场的来源页面无添加/删除入口与合作说明，官方源无法被移除。
3. Tokens Cowork UI 浮动选择表面在明暗主题下渲染正常。
4. 从 v0.3.14 覆盖升级正常，用户数据保留。

## 验证结果

- 系统提示词覆盖经 staging 装配验证：补丁条目正确落盘，上游身份开关语义经源码确认。
- 市场产品源保护带锚点守护；市场测试套件在产品构建下全量通过（含按产品策略跳过的上游用例）。
- 产品布局、插件依赖许可、Desktop 完整检查和 macOS 双架构构建由本次远程 Action 执行。
- Windows 构建复用最终安装器执行上一稳定版覆盖升级及锁文件恢复 smoke。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- Windows 文件被其他进程持续占用时，安装器会安全终止，需要关闭占用程序后重试，不会强制结束可能含未保存数据的进程。
- 受限沙箱基础设施熔断为会话级：触发后需重启会话恢复对应受限模式。
- macOS 正式签名与公证取决于仓库是否配置完整的 Apple 发布凭据；否则使用 ad-hoc 签名。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

# TokensCowork v0.4.5

引入插件市场的 Key 授权体系：连接中心转为市场按授权分发，管理员可按插件配置 API Key 白名单，私有插件仅对获授权的 Key 可见。

## 本次更新

### 市场 Key 授权

- 市场目录支持按客户 API Key 授权：公开插件所有人可见；受限插件仅对获授权的 Key 返回。授权使用 HMAC-SHA256 指纹存储，服务端不保存明文 Key。
- 新增市场后台（/admin/）：按插件维护 Key 白名单、客户备注、停用与到期；管理员凭证仅驻留页面内存。
- 部署流水线在发布市场目录前先运行授权测试。

### 插件分发调整

- 连接中心（tokens-connect）移出内置插件，改为市场分发（按仓库提交锁定），配合授权体系按需开放。

### 开发与构建

- 市场装配覆盖拆分为独立模块（market-auth / market-source）并附自测。
- 开发启动脚本默认使用真实数据模式，并在切换时重置 DSH_HOME 与 APPDATA。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未正式公证的构建首次启动时，需在系统设置的“隐私与安全性”中选择“仍要打开”。

## 验证结果

- 市场授权测试 11 项通过；市场装配覆盖自测 3 项通过。
- 产品装配在隔离 stage 完整重演通过（含市场覆盖拆分与全部产品覆盖锚点）。
- 产品布局、版本钉定、市场名册一致性与快照闸门全部通过。
- 完整的桌面与市场测试套件、运行时闭包、许可证门禁、预设健康检查补丁验收与品牌门禁由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- 已安装连接中心的存量用户不受本次调整影响；新安装需通过市场获取。
- 市场授权状态以本市场为准，不自动同步 New API 的 Key 状态。
- Windows 安装器暂未进行 Authenticode 签名；macOS 构建未经 Apple 公证，首次打开需在系统设置中放行。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

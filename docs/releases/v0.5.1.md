# TokensCowork v0.5.1

修复兼容模式顶部“检查更新”提示不可用的问题，使顶部菜单和托盘复用 TokensCowork 更新插件的检查逻辑。

## 本次更新

- 在产品装配时为更新插件补齐 `check-for-updates` 命令 ID，不修改上游子模块或更新源。
- 更新菜单验收同时检查命令 ID 和文案，补充顶部菜单调用、幂等及上游变动检测测试。
- 沿用 v0.5.0 的 Desktop、DSH 和四个内置插件固定版本，无新增依赖。

## 下载说明

安装包由 GitHub Build Desktop 构建，附件以 Release 实际上传结果为准。

- Windows amd64：`TokensCowork-0.5.1-windows-amd64-installer.exe`
- macOS Apple Silicon：`TokensCowork-0.5.1-macos-arm64-installer.dmg`
- macOS Intel：`TokensCowork-0.5.1-macos-amd64-installer.dmg`

## 安装说明

完全退出应用后安装，升级前建议备份用户数据。此次修复不需要清理缓存或删除配置。未签名 Windows 安装包可能出现 SmartScreen 提示，macOS 签名状态以构建结果为准。

## 验证结果

- 57 项外层构建测试通过。
- 实际 staging 更新插件验证正常检查、模拟断网结果及恢复后再次检查；完整 Profile 加载与更新命令 ID/文案校验通过。
- 用户已确认本地顶部和托盘“检查更新”验证正常。

## 已知限制

本地验证不等于三平台安装升级已验收；安装包仍须通过 CI，并进行安装后验证。更新插件的发布渠道策略未改变。

# TokensHarness v0.1.0

首个 TokensHarness 桌面产品版本以固定的 Desktop、DeepSeek Harness 与插件源码提交完成可复现组装，并提供 Windows 与两种 macOS 架构的安装包。

## 本次更新

### 新增

- 新增纯构建 Superproject，以 Git submodule 固定 Desktop、递归 DeepSeek Harness 和候选插件源码版本。
- 新增隔离的 staging 组装流程，构建过程不会修改任何子模块工作区。
- 新增 Windows amd64、macOS Apple Silicon 与 macOS Intel 三平台安装包构建。
- 新增唯一 `VERSION` 产品版本源、发布说明模板和发布内容校验门禁。

### 修复

- 统一安装包文件版本与 Electron 应用内部版本，避免发布文件名和应用元数据不一致。
- 固定正式 Release 附件清单，`BUILD-INFO.txt` 仅保留在 Actions artifact 中供追溯。

### 优化

- 构建前校验所有 gitlink、子模块 URL、固定提交和插件包身份。
- 在桌面依赖安装后执行运行时闭包、类型、测试和生产依赖许可证检查。
- GitHub Actions 构建页展示各平台结果、版本化 artifact 名称和未签名状态。

## 下载说明

| 系统 | 架构 | 安装包 |
|---|---|---|
| Windows | amd64 | `TokensHarness-0.1.0-windows-amd64-installer.exe` |
| macOS | Apple Silicon | `TokensHarness-0.1.0-macos-arm64-installer.dmg` |
| macOS | Intel | `TokensHarness-0.1.0-macos-amd64-installer.dmg` |

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击安装。
2. 未签名安装器可能出现 SmartScreen 提示，请确认下载地址来自本仓库 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensHarness 拖入“应用程序”。
3. 当前版本尚未进行 Apple 签名和公证，首次启动时需要右键应用并选择“打开”。

## 验证结果

- Windows amd64：由 GitHub Actions 构建 NSIS 安装器，验证 PE 文件并校验 SHA-256。
- macOS arm64：由 GitHub Actions 在 Apple Silicon Runner 构建，执行二进制架构检查和 `hdiutil verify`。
- macOS amd64：由 GitHub Actions 在 Intel Runner 构建，执行二进制架构检查和 `hdiutil verify`。
- 三个平台产物必须来自同一 `0.1.0` 版本和同一 git commit；任一平台失败时不创建 Release。
- Desktop、DeepSeek Harness 与插件子模块提交均由 `product.json` 和 Git tree 双重固定。
- 构建执行 Desktop 测试、类型检查、运行时闭包与生产依赖许可证门禁。

## 已知限制

- Windows 安装器暂未进行 Authenticode 签名。
- macOS 应用暂未进行 Apple 签名和公证。
- 当前不提供 Windows ARM64、Windows 32 位、Linux 安装包或 macOS 32 位安装包。
- `dsh-vision-router` 仍作为固定候选源码存在，但因其 `potrace` 依赖采用 GPL-2.0，当前版本不将该插件分发进 MIT 安装包。
- GitHub Release 仅展示三个安装包和统一 SHA-256 校验文件；各平台 `BUILD-INFO.txt` 保留在 Actions artifact 中供内部追溯。

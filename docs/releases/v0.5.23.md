## 安装说明

### Windows

1. 下载 Windows amd64 安装器，完全退出正在运行的 TokensCowork。
2. 双击安装器，按提示完成安装。
3. Windows 安装器未进行 Authenticode 签名，可能显示 SmartScreen 提示，请核对来源为本仓库 Release。

### macOS

1. 在“关于本机”中确认处理器类型，选择 Apple Silicon 或 Intel 安装包。
2. 完全退出 TokensCowork，打开 DMG，将应用拖入“应用程序”。
3. 从“应用程序”打开 TokensCowork；如出现首次打开确认，点击“打开”。

两个 macOS 安装包均已通过 Developer ID 签名、Apple 公证与票据校验，可按上述步骤安装。

## 已知限制

- 本次构建总耗时 14 分 56 秒；Intel 任务决定总耗时，Apple 公证约 1 分 50 秒，其余时间主要用于源码、依赖、编译和打包。v0.5.21 从首次触发到完成为 23 分 27 秒，包含首次失败与重试，不能将全部差值归因于并行优化；后续耗时仍受 Runner 与网络影响。
- 文本护栏按重复行和字符上限判定，不保证识别所有语义重复；IM 图标重叠、玻璃面板字体清晰度和设置残留绿框未在此次修复。

- 构建与自动化检查不替代真实模型和跨平台人工安装验收；Windows 安装包仍未签名。

## Known Limitations

- Total build duration was 14m56s, determined by the Intel job. Apple notarization took about 1m50s; the remaining time mainly covered source preparation, dependencies, compilation and packaging. v0.5.21 took 23m27s from its first trigger, including an initial failure and retry, so the entire difference cannot be attributed to parallel execution. Future duration still depends on runners and network performance.
- The text guard uses repeated-line thresholds and a character cap and cannot guarantee detection of every semantic loop. IM icon overlap, glass-panel font clarity and the residual Settings outline were not addressed.
- Plugin cards on the English download page retain some Chinese names and descriptions. Gray market cards have not been visually accepted under real-host themes.
- Automated checks do not replace real-model and cross-platform manual installation acceptance. Windows remains unsigned.

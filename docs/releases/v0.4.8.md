# TokensCowork v0.4.8

模型管理器升级到 0.2.16：视觉识别失败后不再反复重试；插件市场后台完成管理资产拆分与服务端模块完善，运维脚本独立归档，访问测试覆盖扩展到 31 项。

## 本次更新

### 模型与视觉

- 模型管理器 0.2.16：视觉桥接在识别确定性失败后停止重试，避免对同一失败输入反复发起请求，降低延迟与消耗。

### 插件市场后台

- 管理界面资产拆分为独立的脚本与样式模块，服务端请求处理、组织与插件访问服务完善，接口分层更清晰。
- Cloudflare 运维脚本归入独立 ops 目录，部署工作流与文档同步。
- 市场访问测试扩展到 31 项。

## 安装说明

### Windows

1. 下载 Windows amd64 安装器并双击运行。
2. 覆盖安装会保留 TokensCowork 用户数据、插件配置与市场安装记录。
3. 未签名安装器可能出现 SmartScreen 提示，请确认文件来自本仓库官方 Release。

### macOS

1. Apple Silicon 用户下载 `arm64`，Intel 用户下载 `amd64`。
2. 打开 DMG，将 TokensCowork 拖入“应用程序”。
3. 未经公证的构建首次启动时，需在系统设置的“隐私与安全性”中选择“仍要打开”。

## 验证结果

- 市场访问测试 31 项通过；市场覆盖自测(授权、更新、对话框定位、装配来源)通过。

- 完整的桌面与市场测试套件、运行时闭包、许可证门禁、预设健康检查补丁验收与品牌门禁由发布流水线在构建各平台安装包前执行，未全部通过不会发布。

## 已知限制

- 市场授权状态以本市场为准，不自动同步 New API 的 Key 状态。
- Windows 安装器暂未进行 Authenticode 签名，可能触发 SmartScreen 提示。
- macOS 构建未经 Apple 公证，首次打开需在系统设置中放行。
- 当前不提供 Windows ARM64、Windows 32 位或 Linux 安装包。

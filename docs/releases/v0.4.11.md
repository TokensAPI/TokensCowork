# TokensCowork v0.4.11

桌面端插件市场接入 TokensCowork 自建 npm Registry，并与市场服务完成能力协商：只有声明支持自建源的桌面版本会收到这类条目，旧版本继续收到它们能解析的目录，插件展示、安装和更新的公开与受限完全由市场后台的访问范围决定。

## 本次更新

- 桌面端目录识别 `registry: tokenscowork` 的插件条目：此前的桌面版只认公开 npm 来源，自建源插件即使后台公开上架也不会出现在插件市场里。
- 目录请求携带 `x-dsh-catalog-registries` 能力声明，市场只对声明过的客户端下发自建源条目；旧桌面版本的目录校验是整页失败语义，没有这层协商时一条自建源条目就会让旧版插件市场整页加载失败。
- 自建源插件的元数据和安装包通过市场 `/registry/` 代理获取；受限插件使用当前用户自己的 API Key 鉴权，桌面端不接触 Registry 凭据，日志中的凭据参数一律脱敏。
- 市场后台的访问范围成为唯一可见域判定：公开插件所有人可见可装，受限插件仅授权的组织或 API Key 可见可装，包放在 Registry 哪个作用域不再影响分发。
- 自建 Registry 服务独立部署并公私共存：`@tokensapi-private/*` 需登录，其余包匿名可读并回源 npmjs 缓存，市场 Worker 以只读服务账号访问。
- Desktop、Harness 和其他内置插件的固定版本不变，生产依赖图不变。

## 下载说明

从本仓库 Release 页面下载 Windows amd64、macOS Apple Silicon（arm64）或 Intel（amd64）对应安装包，并核对同页 SHA256 校验文件。

## 安装说明

- Windows：退出应用后运行安装器，覆盖安装保留用户数据。
- macOS：将 DMG 内的应用拖入“应用程序”并替换旧版。
- 升级后无需额外配置：插件市场自动展示自建源的公开插件；受限插件在设置中填入被授权的 API Key 后可见。

## 验证结果

- 市场服务端 135 项测试全部通过（含自建源公开/受限双向、代理凭据与权限闸门用例）；`npm --prefix market run verify` 与生产部署流水线绿灯。
- 生产环境验收：私有作用域验收包设为公开后匿名可见、可下载（元数据与 tarball 均 200）；改回受限后匿名立即 403、授权 API Key 仍可下载；后台把受限插件改公开需要明确确认。
- Registry 线上验证：匿名读取公开包 200、私有作用域 401、未知包 404；发布、回源 npmjs 与只读服务账号行为符合预期。
- 打包注入的自建源支持由构建期锚点校验保护，锚点漂移会中断打包待人工复查。
- 未执行会话里的工具、未调用付费模型，真实网关与各平台安装体验仍需验证。
- Windows、macOS 两架构的完整构建、生产许可证和产物检查交由 Build Desktop；所有构建通过后才发布安装包。

## 已知限制

- 桌面端展示自建源插件要求升级到本版本；旧版桌面收不到这些条目，也不提示原因。0.4.10 预发布版能安装自建源插件但收不到条目下发，应直接升级到本版本。
- 受限插件的可见性依赖用户在设置中配置的 API Key；Key 被吊销或过期后条目会消失而不单独提醒。
- Windows 安装器未签名，可能提示 SmartScreen；macOS 若采用临时签名而非公证签名，首次启动可能需要在系统设置中放行。
- 不提供 Windows ARM64、32 位或 Linux 安装包。

        新建插件
        
            
          
        
          
        
            
        新插件默认保存为草稿。已上架插件若更换包、仓库或版本，会退回草稿，需重新检查后上架；仅修改名称、简介即时生效。
        
            
        
              
              
        从 npm 读取时自动填写，也可自定义；创建后不可修改。
        
            
        
            
        
              
            
        
            
        
              
            
        
            
        
              
            
        
            
        
              
            
        
            
        
              README 简介建议
              
        
              
        
              
            
        
            
        
              
            
        
            
        
              
        
                
              
        
              
        
                
              
        
            
        
            
        
              
              
        兼容来源保留旧版的公开 npm 安装方式；新版经市场从自建仓库下载。仅自建的新插件请选择自建 Registry。新插件统一使用 @tokensapi/包名：仓库限制直连，用户公开或受限由市场范围决定，无需改包名。公开 npm 历史包和第三方兜底规则下的包不受市场权限保护。
        
            
        
            
        
              
            
        
            
        
              
              
        npm 插件首次上架后自动跟随所选 Registry 的稳定版 latest，不需要重复保存或上架。名称、简介与权限保持不变；下架和草稿不会自动上架。依赖许可证检查应在发布前完成。Registry 查询失败或 latest 为预发布版时，暂不向应用提供该条目。

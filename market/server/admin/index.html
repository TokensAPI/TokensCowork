README 简介建议

npm 插件首次上架后自动跟随所选 Registry 的稳定版 latest，不需要重复保存或上架。名称、简介与权限保持不变；下架和草稿不会自动上架。依赖许可证检查应在发布前完成。Registry 查询失败或 latest 为预发布版时，暂不向应用提供该条目。
